## 3.1.2 变量的作用域和生命周期
1. 变量的作用域和生命周期
	- 作用域：变量在多大范围内有效
	- 生命周期：变量能存多久
2. 全局变量和作用域

|      | 生命周期             | 作用域         |
| ---- | ---------------- | ----------- |
| 全局变量 | 程序开始->程序结束       | 整个程序的所有文件   |
| 局部变量 | 进入函数/代码块->退出块时销毁 | 仅定义他的函数/代码块 |
## 3.1.3 全局变量
1. 全局变量的作用域和生命周期都很大。它的生命周期从程序创建开始，一直持续到程序结束。同时它的作用域是整个程序里的所有文件，这意味着你可以在别的文件里访问它。跨文件访问全局变量是我们经常使用的技巧

# 3.2 变量在SRAM里的分布
## 3.2.1 单片机的FLASH和SRAM
1. 内存和硬盘：如果数据存储在内存里，那么断电之后就消失了；而如果存储在硬盘里咋，即使断电后数据也能保存下来![[Pasted image 20261004174554.png]]
2. 单片机和电脑非常像，Flash就相当于电脑上的硬盘，SRAM就相当于电脑上的内存![[Pasted image 20261004174714.png]]
	- cotex-M3是单片机的内核，内核负责运算，就像电脑的CPU
	- 总线矩阵相当于电脑的主板
	- Flash相当于硬盘，程序和常量存储在这里
	- SRAM相当于内存，变量存储在这里
3. FLASH里:程序当中需要长期存储的、不可变的部分                 
4. SRAM里:临时存储的、经常变化的部分

|阶段|住哪|特点|
|---|---|---|
|编译/烧录时|**FLASH**（仓库）|掉电不丢。代码、常量、`.data` 的**初始值**都存在这|
|上电启动时|启动代码干活|把 `.data` 从 FLASH **拷贝**到 SRAM；把 `.bss` **清零**；设好栈指针|
|运行时|**SRAM**（工作台）|掉电就没了。变量、堆、栈都在这|
