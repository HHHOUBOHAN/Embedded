## 3.1.2 变量的作用域和生命周期
1. 变量的作用域和生命周期
	- 作用域：变量在多大范围内有效
	- 生命周期：变量能存多久
2. 全局变量和作用域

|      | 生命周期             | 作用域         |
| ---- | ---------------- | ----------- |
| 全局变量 | 程序开始->程序结束       | 整个程序的所有文件   |
| 局部变量 | 进入函数/代码块->退出块时销毁 | 仅定义他的函数/代码块 |
## 3.1.3 全局变量
1. 全局变量的作用域和生命周期都很大。它的生命周期从程序创建开始，一直持续到程序结束。同时它的作用域是整个程序里的所有文件，这意味着你可以在别的文件里访问它。跨文件访问全局变量是我们经常使用的技巧
## 3.1.4 局部变量
1. 局部变量：在函数/代码块内部创建的变量![[Pasted image 20261004170658.png]]
## 3.1.5 静态全局变量
1. 静态全局变量：全局变量声明时加上static关键字，仅存在文件内部，外部不能访问它![[Pasted image 20261004173053.png]]

|        | 生命周期       | 作用域        |
| ------ | ---------- | ---------- |
| 全局变量   | 程序开始->程序结束 | 整个程序的所有文件  |
| 静态全局变量 | 程序开始->程序结束 | 仅在创建它的文件内部 |
## 3.1.6 静态局部变量

|        | 生命周期                | 作用域         |
| ------ | ------------------- | ----------- |
| 局部变量   | 进入函数/代码块->退出块时销毁    | 仅定义它的函数/代码块 |
| 静态局部变量 | 初次调用创建它的函数时->应用程序退出 | 仅定义它的函数/代码块 |

# 3.2 变量在SRAM里的分布
## 3.2.1 单片机的FLASH和SRAM
1. 内存和硬盘：如果数据存储在内存里，那么断电之后就消失了；而如果存储在硬盘里咋，即使断电后数据也能保存下来![[Pasted image 20261004174554.png]]
2. 单片机和电脑非常像，Flash就相当于电脑上的硬盘，SRAM就相当于电脑上的内存![[Pasted image 20261004174714.png]]
	- cotex-M3是单片机的内核，内核负责运算，就像电脑的CPU
	- 总线矩阵相当于电脑的主板
	- Flash相当于硬盘，程序和常量存储在这里
	- SRAM相当于内存，变量存储在这里
3. FLASH里:程序当中需要长期存储的、不可变的部分                 SRAM里:临时存储的、经常变化的部分
