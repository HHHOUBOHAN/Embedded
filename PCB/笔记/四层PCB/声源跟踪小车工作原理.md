# 3.1 麦克风声音检测原理
1. 声信号 → 电信号                                                                                                                        ![[Pasted image 20261008204050.png]]
2. 检测原理：驻极体是两个薄膜相当于电容，出厂时候会灌入一定电荷量Q，**V = Q / C**，外面有声音信号进来的时候，这个信号就会带动薄膜进行震动（一个薄膜固定，一个薄膜随声音震动），震动之后C会发生变化（**C = εS / d**距离发生了变化），从而使电压发生变化，G点的电压发生变化以后，DNS这个可调电阻就会发生变化 ， 驻极体一直有Q也就是一直有电压，场效应管就一直工作在放大状态，放大状态也叫可调电阻状态，通过串联一个电阻，通过这个可调电阻状态，从而检测对应电压，从而实现声音信号转化为电信号                                                                         ![[Pasted image 20261009103812.png]]
# 3.2 声音检测放大电路设计
1. 放大电路：三极管，运放（LM358）（同相 反相）![[Pasted image 20261009104526.png]]
2. 运算放大器：![[Pasted image 20261009123742.png]]
	- `+`：同相输入端
	- `−`：反相输入端
	- `OUT`：输出端
	- 运放可以将很小的输入电压差放大，理想运放的基本关系可以写成：$\[ U_o=A(U_+-U_-) \]$
	- \(U_o\)：输出电压
	- \(U_+\)：同相端电压
	- \(U_-\)：反相端电压
	- \(A\)：开环电压增益，通常非常大
3. 同相放大：输出电压与输入电压同极性，输入增加，输出也增加
4. 反向放大：输出电压与输入电压反极性，输入增加，输出向相反方向变化
