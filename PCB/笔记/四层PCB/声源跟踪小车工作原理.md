# 3.1 麦克风声音检测原理
1. 声信号 → 电信号                                                                                                                        ![[Pasted image 20261008204050.png]]
2. 检测原理：驻极体是两个薄膜相当于电容，出厂时候会灌入一定电荷量Q，**V = Q / C**，外面有声音信号进来的时候，这个信号就会带动薄膜进行震动（一个薄膜固定，一个薄膜随声音震动），震动之后C会发生变化（**C = εS / d**距离发生了变化），从而使电压发生变化，G点的电压发生变化以后，DNS这个可调电阻就会发生变化 ， 驻极体一直有Q也就是一直有电压，场效应管就一直工作在放大状态，放大状态也叫可调电阻状态，通过串联一个电阻，通过这个可调电阻状态，从而检测对应电压，从而实现声音信号转化为电信号                                                      ![[Pasted image 20261008205246.png]]
