# 1.0 四层板层叠结构
## 1.0.1 分层方案
![[Pasted image 20261008182605.png]]
1. GND（**地层 / Ground Plane**） BOTTOM(信号层)  TOP(信号层)    PWR1（电源层 / Power Plane） 
2. 方案一（经典）：大部分器件放置在TOP中，重要信号线，器件都是在顶层,TOP参考层就是GND层
	- **信号有参考**：顶层走线紧挨着地层，信号回流最顺畅，抗干扰强。
	- **电源最稳定**：中间电源层和地层靠得近，形成天然电容，滤波效果好。
	- **上下有屏蔽**：中间两层像一堵墙，隔开顶层和底层的信号，防止互相干扰
3. 方案二：GND和BOTTOM 对调,TOP参考层是Power ,此时重要信号,主要器件要在BOTTOM完成
4. 方案三：顶层GND，底层BOTTOM ，中间两层处理信号，以插件为主的PCB
# 1.1 正片层负片层的概念
1. 正片层（与平常设计一致）：正片设计默认是无铜的，走线和铺铜的地方意味着这里的铜保留，没有走线和铺铜的地方铜被清除了
2. 负片层：负片设计默认是有铜的，走线和铺铜的地方意味着这里的铜被清除了，没有走线和铺铜的地方铜被保留
# 1.2 热焊盘和反焊盘的概念
1. 热焊盘：引脚与大面积的铺铜完全连接，容易造成分散散热而产生虚焊。因此对于接地引脚与大面积敷铜连接时，需要将实铜连接方式改为，变成十字空心连接，以减少焊接中热量对周围的传导，便于人工焊接（让散热变慢）![[Pasted image 20261008185407.png]]
2. 反焊盘：指的是**负片**与焊盘的距离。(仅限于中间层，顶层与底层中这样不算) 颜色浅的是铜皮  红色那部分不是铜皮![[Pasted image 20261008185347.png]]
# 1.3 阻抗概念引入
1. 特征阻抗： 又称“特征阻抗”，他不是直流电阻，属于长线传输中的概念    
2. 在高频范围内，信号传输过程中，信号沿到达的地方，信号线和参考平面（电源或地平面）间由于电场的建立，会产生一个瞬间电流，如果传输线是各向同性的，那么只要信号在传输，就始终存在一个电流I，而如果信号的输出电平为V，在信号传输过程中，传输线就会等效成一个电阻，大小为V/I，把这个等效的电阻称为传输线的特性阻抗Z，信号在传输的过程中，如果传输路径上的特性阻抗发生变化，信号就会在阻抗不连续的结点产生反射，影响特性阻抗的因素有：介电常数，介质厚度，线宽，铜箔厚度
3. 一般，介质厚度，**线距**越大阻抗值越大；介电常数、铜厚、**线宽**、阻焊厚度越大阻抗值越小  线宽和线距能有自己决定 剩下那些由PCB厂家决定
4. 为啥要控制阻抗（阻抗匹配）：信号不能发生反射，如果发生反射接收到的信号是不完整的，阻抗不匹配的时候会形成明显的反射波，![[Pasted image 20261008193257.png]]
# 1.4 嘉立创阻抗神器详解
1. 链接：[嘉立创阻抗计算](https://tools.jlc.com/jlcTools/index.html#/impedanceCalculatenew)
2. 常见的阻抗线
	- 单端阻抗：一根信号线 + 下方一个完整参考平面。单独一根线做阻抗线
	- 差分阻抗： 两根线，等长、等间距，下方一个完整参考平面，长度相同且大部分间隙一样的两根线做阻抗线
	- 共面单端（包地处理）：一根信号线，**下方有参考平面**，同时**线的左右两侧（同一层）也有铜面**，并且这些铜面通过**规则排列的过孔**连接到下方的 GND 平面。单端阻抗外面有铜面环绕，并且铜面到阻抗线间隙一样且规则钻孔
	- 共面差分：差分阻抗线外面有铜面环绕，并且铜面到阻抗线间隙一样且规则钻孔

3. 阻抗设计的注意事项
	- 阻抗线可以设计在外层（如上表四种形式均为外层阻抗），也可以设置在内层，层数变多以后，内层也会进行走线
	- 阻抗值的大小依产品设计及芯片类型定，一般的情况下，元器件厂商有设定好信号源和接收端的阻抗的(如SDIO：单端50ohm，USB：差分90ohm)
	- 阻抗线一定要有阻抗参考层，一般以相邻的接地或电源层做参考层(如顶层阻抗线，那么参考层一般为第二层)
	- 阻抗参考层作用是为了给信号提供回流路径，并起电磁屏蔽作用，因此阻抗线对应的参考层位置必须是实心铜皮覆盖
