# 3. 电源设计相关基础知识（DCDC芯片，LDO芯片）
> 电源稳压器（Power Regulator）是一种在电源电压或者负载电流发生变化的时候，依然能够提供稳定输出电压的元件
> DC/DC转换器一种是开关电源稳压器，指利用电容、电感的储能的特性，通过可控开关（MOSFET等）进行高频开关的动作，将输入的电能储存在电容（感）里，当开关断开时，电能再释放给负载，提供能量。
## 3.1 LDO芯片（AMS1117电源芯片）
1. 介绍                 ![[Pasted image 20260818220548.png]]
2. 工作原理（小灯泡实验）
	- 小灯泡实验![[Pasted image 20260818221230.png]]
	- LDO芯片结构框图  : 误差放大器 调整管 电压基准 采样电路      ![[Pasted image 20260818221939.png]]  
	- LEO电气特性
		- LEO外围器件少，电路简单，成本低，通常只需要一两个旁路电容
		- LDO负载响应快，输出纹波小，噪声小
		- LDO效率低，输入输出压差不能太大
		- LDO只能降压
		- LDO输出电流有限，最高可能就只有几A
		- 应用场合：低压差，低纹波，低噪声
## 3.2 DCDC开关稳压器
 1. DC/DC转换器一种是开关电源稳压器，指利用电容、电感的储能的特性，通过可控开关（MOSFET等）进行高频开关的动作，将输入的电能储存在电容（感）里，当开关断开时，电能再释放给负载，提供能量。

## 3.4 基准电压源

### 4.2.3 复位电路
> 本项目：RC上电复位 + 按键手动复位

1. 原理图                                                                                                                                                   ![[Pasted image 20260819205824.png]]
2. 工作原理
	- 上电自动复位：
		 - 刚上电，电容两端电压不能突变，相当于短路，所以RST引脚初始为低电平（0V）
		 - 随着`3.3V`通过`10KΩ`给电容供电，RST引脚的电压会按指数曲线逐渐上升
		 - 当电压上升到芯片识别为高电平阈值时（通常为 0.7×VCC ≈ 2.3V），复位结束，芯片开始正常工作
		 - 这个充电时间（复位延时）  就是为了等待电源和时钟稳定，防止芯片刚上电就乱跑程序
	- 按键手动复位（主动模式）
		- 当你按下`SW1`时，RST引脚被直接拉到GND(低电平)
		- 芯片检测到持续的低电平（通常需要几微秒到几毫秒），立即触发硬件复位
		- 松开按键后，C24再次通过R10充电，芯片重新启动程序
	- 按键消抖与防干
		- 电容不仅是延时电容，还起到这个**硬件消抖**作用。机械按键在按下和松开的瞬间会产生几毫秒的抖动（高低电平乱跳），电容能吸收这些毛刺，避免芯片误判多次复位
3. 元器件作用：
	- 电阻：如果没有这个电阻，复位按键按下以后**3.3V 电源会直接对地（GND）短路** ，
	- 电阻可以配合电容形成上电延时（没有电阻，直接给电容充电，瞬间充电电流极大，且 RST 引脚电压会瞬间飙到 3.3V，**上电复位延时几乎为 0**，芯片电源还没稳定，复位就结束了，导致芯片启动失败，有了这个电阻，限制了充电速度）
	-  **隔离外部干扰，防止“死机”**：RST 引脚内部通常是一个高阻抗的 MOS 管栅极，极易受外界静电或电磁辐射干扰。R10 与 C24 组成低通滤波器，能将高频杂讯滤除，同时如果外部强干扰传入，电阻也会限制流入芯片引脚的电流，起到缓冲保护内部芯片和内部电路的问题
