## 5V 转 3.3V 的稳压电源电路
1. PCB                                                                             ![[Pasted image 20260707172713.png]]
2. 作用：
```
USB或其他地方提供的 +5V
          ↓
      ME6211稳压
          ↓
      输出稳定3.3V
          ↓
    给单片机等器件供电
```
3. 引脚功能

|  引脚 | 名称   | 作用    | 图中接法   |
| --: | ---- | ----- | ------ |
|   1 | VIN  | 电源输入  | 接 +5V  |
|   2 | VSS  | 地     | 接 GND  |
|   3 | CE   | 芯片使能  | 接 +5V  |
|   4 | NC   | 内部不连接 | 悬空     |
|   5 | VOUT | 稳压输出  | 输出3.3V |
4. 原理：
```
1. 左侧接入+5V。

2. C1和C3过滤输入电源的杂波。

3. +5V同时接到VIN和CE。
   VIN负责供电；
   CE被拉高，使芯片一直开启。

4. ME6211把5V稳压成3.3V。

5. 3.3V从VOUT输出，并命名为VCC。

6. C4和C2稳定、过滤3.3V输出。

7. VSS接GND。

8. NC脚不使用。
```
5. 全过程
``` 
USB提供5V
   ↓
C1和输入电容过滤5V
   ↓
5V进入ME6211的VIN
   ↓
CE也得到5V，芯片开启
   ↓
芯片内部把5V稳定成3.3V
   ↓
3.3V从VOUT输出
   ↓
输出电容稳定3.3V
   ↓
通过VCC给单片机等器件供电
   ↓
电流经过GND返回USB电源
```

## 滤波电容电路
1. PCB                               ![[Pasted image 20260707193205.png]]
2. 四个 100nF 电容都并联在 `VCC` 和 `GND`
3. 作用：
``` 
 稳定 VCC 电压 
 过滤高频干扰 
 给芯片瞬间补充电流 
 防止单片机复位、程序跑飞 
```
4. 工作过程
	- 正常供电时，VCC 给电容充电：VCC → 电容充电，电容充满后，基本不会让直流电持续流向 GND，所以不是短路
	- 芯片突然需要较大电流时，例如单片机内部大量晶体管突然切换
		`芯片突然需要电流        ↓VCC可能瞬间下降        ↓附近的100nF电容立即放电        ↓给芯片补充电流        ↓VCC保持稳定`
	- 电源出现高频尖峰时
		- `VCC出现干扰尖峰        ↓电容吸收一部分变化电流        ↓干扰通过电容流向GND        ↓送给芯片的电压更干净`
## 晶振
1. PCB![[Pasted image 20260707194959.png]]
2. 原理图解析：
```
单片机 OSCIN ──┐
               │
           8MHz晶振
               │
单片机 OSCOUT ─┘

OSCIN  ── C12 18pF ── GND
OSCOUT ── C11 18pF ── GND
```
3. 作用：给单片机提供工作节拍，单片机执行程序需要时钟
4. 工作流程：
```
上电产生微小信号
→ 内部放大
→ OSCOUT输出
→ 经过晶振反馈到OSCIN
→ 不断循环
→ 形成稳定8MHz时钟
```
