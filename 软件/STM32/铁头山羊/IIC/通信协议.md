# IIC通信的基本流程
1. 主机发送起始位（SCL为高，SDA 从高到低，宣布一次通信开始），地址+读写位（主机发7位从机地址+1位R/W（1=读，0=写），广播给所有从机），从机应答ACK(地址匹配的从机在第九个时钟把SDA拉低，表示“我在，继续”)，数据传输（每8位一个字节+**1应答位**，逐字节传完（主→从 或 从→主）），停止位STOP（SCL为高时，SDA由低→高，总线释放，通信结束）![[Pasted image 20260903190033.png]]

# 起始位和停止位
1. 起始位：SCL高电压，SDA从高电压到低电压（下降沿）
2. 停止位：SCL高电压，SDA从低电压到高电压（上升沿）
3. 示意图                                                                                   ![[Pasted image 20260903192147.png]]
# 寻址
1. 寻址时主机会向从机发7位地址和读写位9（R（1）/W（0）），然后会从机进行应答(ACK)
2. 应答逻辑：发送完7位地址和读写位以后，主机SDA引脚会写1，相当于主机释放SDA，上拉电阻将其上拉到高电平，如果有从机应答，从机就会将SDA拉低，主机检测到低电压，就相当于收到了ACK
