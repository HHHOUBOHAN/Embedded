# 思路
定义数据的时候一定要考虑这个static和这个const


```c
 if((uint32_t)mode>=(uint32_t)APP_MODE_COUNT)

    {

        return false;

    }

    return true;
    
    
     return ((uint32_t)mode < (uint32_t)APP_MODE_COUNT);  
     以上两者返回值是一样的  最好还是下面这样写 这样写更加简洁
     
```

2. 对比数据的时候一定要考虑这个转换类型  不要上去就直接比较
	- 规则：无符号类型 vs 有符号类型，有符号值自动转为无符号数再比较。
3. 凡是结构体作为入参，只要不需要在函数内部修改副本，一律传指针。
	- 嵌入式裸机栈空间很小，如果大量的结构体拷贝容易栈溢出
	- 传指针只压入地址，栈压力极小
4. 有返回值，但是这个有这个（void）就不用这个返回值
```
(void)AppCommand_Post( APP_COMMAND_CONFIG_NEXT, APP_COMMAND_SOURCE_KEY, key_event->timestamp_ms );
```
5. 传参的时候，一定要考虑这个**空指针防护**
