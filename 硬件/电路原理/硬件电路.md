# [下拉电阻](https://www.bilibili.com/video/BV1ZU4y1Q7eo?t=3.9)
1. 概念： 
2. 作用：将一个不确定的信号钳位在低电平
	1. 不确定信号的产生：两块N型半导体之间的阻抗太大了，就好似断开，所以这个`P`型半导体的电压飘忽不定，对应引脚的信号也是不确定的![[Pasted image 20260804182609.png]]
3. 原理：对应引脚的信号也是不确定的，当接入这个下拉电阻的时候，电阻和三极管是串联关系，三极管内部阻抗非常高，大到下面接的这个下拉电阻的阻值都可以直接忽略不计，根据串联分压可得这个电阻上的电压接近0V, 所以加上这个下拉电阻，就把这个信号钳位到低电平
4. 直接接地是否可行：
- 直接接地，原本放电阻的地方，电压也是0V，但是单片机输入有高有低，
- 在默认状态下，下拉电阻可以让信号稳定在`0V`   
- 当输入为`5V`的时，下拉电阻可以巧妙的把这信号钳位到高电平，可以让这个信号在高低电平之间转换![[Pasted image 20260804183556.png]]
# [上拉电阻](https://www.bilibili.com/video/BV1W34y1579U?t=2.3)
1. 概念:把 GPIO 引脚通过一个电阻接到**高电平电源 (VCC)**。![[Pasted image 20260804183924.png]]
2. 作用：提高驱动能力，将一个不确定的信号钳位到高电平![[Pasted image 20260804184638.png]]
3. 不确定的信号：引脚属于开漏输出的时候，上面的MOS永远时断开的，相当于一个无限大的电阻，当将下面的MOS截至的时候，下面也相当于一个连接一个无穷大的电阻，两个无穷大的电阻相当于断开，所以输出的信号时不确定的，当加一个电阻之后，输出高电平![[Pasted image 20260804185822.png]]![[Pasted image 20260804190436.png]]
4. 工作原理：
- 不加入上拉电阻时等效电路：之所以加上下拉以后这个电压降低，是因为他的内阻和外接电阻时串联关系,电阻分压，所以电压降低![[Pasted image 20260804184840.png]]
- 当加上上拉电阻之后：应为接的都是这个`5V`电压，所以这个上拉电阻和这个内阻时并联关系，并联之后上面总电阻减少，根据分压原理上面电阻小，下面电阻分压多，从而提高驱动能力![[Pasted image 20260804185421.png]]
- 本质：上拉电阻于单片机内阻并联，减少上拉和内阻并联的阻值，从而输出电压变高

# IIC工作原理
## I2C 总线最核心的机制：多个设备为什么不会同时发送导致冲突
1. I2C 不是多个设备轮流主动发送，而是一个主机（Master）控制总线，多个从机（Slave）等待被访问
```
              SDA
               |
STM32 Master ---+----- OLED
               |
               +----- MPU6050
               |
               +----- EEPROM
               |
               +----- 温度传感器

              SCL
               |
STM32 Master ---+----- 所有设备
```
这些OLED、MPU6050、EEPROM **不会主动抢着发送**。 只有这个STM32 要读取对应的元器件的数据的时候，才会进行这个发送
2. I2C 有设备地址机制
- 这个设备地址机制就是解决了这个对应元器件的如何响应的问题
- stm32会发送地址，所有的元器件 ，都会响应，只有这个地址匹配，才会响应ACK，从而开始工作
- I2C 从机没有主动权,不会乱发送数据
