# 单片机最小系统
1. 单片机最小系统：是指用最少的元件组成的单片机可以工作的系统。对于51系列单片机来说，单片机+晶振电路+复位电路，便组成了一个最小系统。晶振电路是单片机的振荡电路，通过晶振来放大输出信号。复位电路则用于重置单片机的系统状态，使其重新初始化。4
2. 电源电路：单片机最小系统中的电源是指能量的来源，其中VCC(40脚）将电源的正极和GN口(20脚)视为电源的输入和输出。接地端（电源负顺）则用于与地面形成电气连接。
3. 外围功能电路：包括按键检测，Led指示灯，排针引出等

### 元器作用
#### 下拉电阻
1. 连接方式：
```
RST → 10k → GND
```
2. 工作原理
	- 它的作用是让 RST 在正常情况下保持低电平
	- 正常工作： `RST ≈ 0V`
	- 电路为“高电位复位”，RST为低电平，单片机正常工作
#### 手动复位按键
1. 连接方式：
```
+5V → 按键 → RST
```
2. 工作原理：
	- 按键没有按下时，线路断开。
	- 按键按下后：`RST 直接连接到 +5V`, 单片机检测到高电平，进入复位状态。
	- 松开按键后，RST 又被 R4 拉回低电平，单片机重新开始运行

# PCB布局
## 要求
### 通用要求
1. 合理安排布局，元器件之间应相互平行或者**垂直排列，以求整齐、美观；元件排列紧凑**，在整个版面上应分布均匀、疏密一致，所有元器件均放置在顶层
### 特殊要求
1. 必须根据元器件的电气特性和使用特点来布局（这个点非常重要），举例如下：对于各种接口、按键和排针，需要放在板子边缘，方便插接，对于屏幕和主控芯片等，一般放在板子中央，对于电源电路，一般放在板子的电源输入旁边并且要注意电流路径和滤波电容位置（非常重要），对于晶振要靠近单片机晶振引脚摆放等
2. 不要把元器件看成二维物体，而是应该看成三维物体，有时空间有干涉的情况需要考虑
3. 元件的布局应该采用模块化，也就是同一个模块电路的元件应该放同一个区域，按照就近原则来布局，不能东一个西一个
## 过程
1. 放置板框，设置圆角，加入过孔，过离边缘为2.6mm 设置好后直接进行锁定防止位置发生改变
2. 布局：快捷键 交叉选择（shift+x） 布局传递(crtl+shift+x )电源模块  
3. 滤波电容按照**先大后小**方式来放置
4. 晶振电路一定要靠近单片机的晶振引脚放置 
5. 尽量使这个晶振在这个晶振引脚保持一个轴对称![[Pasted image 20260816170119.png]]类似于这种，这样就保持两条线使等长的，这种方式叫做**差分对**
6. 底层和顶层的切换快捷键是`alt+B`   专业版ALT+T切换到顶层，ALT+B切换到底层
7. 疏密一定要一致 这个非常重要

## PCB布线要求 
1. 顶层优先原则：尽量顶层布线
2. 电源线原则上要加粗:因为电源线是要给电路板各个模块供电的，电源线加粗有利于电流在主干道上流通；在日常PCB设计中，在25℃时，对于铜厚为10z(盎司)的导线，10mil线宽能够承载0.65A电流，40mi线宽能够承载2.3A电流
3. 同一层内走线大于`90°`：同一层走线禁止`90°`或者走锐角，从原理上讲，锐角直角走线会造成走线阻抗不连续，对于信号的传输有影响，推荐走线`135°`或者圆弧布线
4. 注意电流路径和电容的摆放位置：电源要先经过电容滤波再给后级，去耦电容要贴近芯片引脚放置，并就近接地
5. 高频信号线尽可能短，并做好与其他信号的屏蔽隔离。为了降低相邻走线之间的串扰，尽量避免相邻层平行走线，走线应遵循3W原则：相邻层信号线应采用正交方向。差分线布线尽量等距等长。
6. PCB布线要尽量远离安装孔与电路板边缘：在PCB钻孔加工中，很容易会切掉一部分导线，为了电路板功能，应尽量远离这些位置。
7. 需要添加泪滴。
## PCB布线顺序
关键元件优先，关键信号线优先，密度优先
1. 密度优先原则：从单板连线最密集的区域开始布线
2. 优先关键元器件：如口口R、射频等核心部分应优先布线，类似信号传输线应提供专层、电源、地回路。其他次要信号要顾全整体，不可以和关键信号相抵触。
3. 关键信号线优先：电源，模拟小信号，高速信号，时钟信号和同步信号等关键信号优先布线
4. 布线小技巧
	- 线间距：
	- 晶振外围屏蔽：打**地过孔**  外径24mil  内径12mil 网络GND
	- 原则上不要在元器件中间走线
	- shift+B 重建铺铜
