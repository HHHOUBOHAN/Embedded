# 3.1 麦克风声音检测原理
1. 声信号 → 电信号                                                                                                                        ![[Pasted image 20261008204050.png]]
2. 检测原理：驻极体是两个薄膜相当于电容，出厂时候会灌入一定电荷量Q，**V = Q / C**，外面有声音信号进来的时候，这个信号就会带动薄膜进行震动（一个薄膜固定，一个薄膜随声音震动），震动之后C会发生变化（**C = εS / d**距离发生了变化），从而使电压发生变化，G点的电压发生变化以后，DNS这个可调电阻就会发生变化 ， 驻极体一直有Q也就是一直有电压，场效应管就一直工作在放大状态，放大状态也叫可调电阻状态，通过串联一个电阻，通过这个可调电阻状态，从而检测对应电压，从而实现声音信号转化为电信号                                                                         ![[Pasted image 20261009103812.png]]
# 3.2 声音检测放大电路设计（没听懂）
1. 放大电路：三极管，运放（LM358）（同相 反相）![[Pasted image 20261009104526.png]]
2. 运算放大器：![[Pasted image 20261009123742.png]]
	- `+`：同相输入端
	- `−`：反相输入端
	- `OUT`：输出端
	- 运放可以将很小的输入电压差放大，理想运放的基本关系可以写成：$\[ U_o=A(U_+-U_-) \]$
	- \(U_o\)：输出电压
	- \(U_+\)：同相端电压
	- \(U_-\)：反相端电压
	- \(A\)：开环电压增益，通常非常大
3. 同相放大：输出电压与输入电压同极性，输入增加，输出也增加
4. 反向放大：输出电压与输入电压反极性，输入增加，输出向相反方向变化
5. 输入信号：直流 交流
6. 电容作用：隔直通交
# 3.3 红外避障电路设计
1. 红外发生二极管 红外接收二极管
2. 原理：两队红外检测电路，第一个和第三个是红外发射电路，第二个和第四个是红外检测电路![[Pasted image 20261009133935.png]]
	- 发射：3.3V通过电阻，限制电流让LED发出红光
	- 接收：U5不发光，类似于一个光控制电流源，光越强，U5产生的电流越大，反之更弱，光电管输出的是电流，但是后面的芯片需要电压进行检测，而添加电阻就能把电流转换成电压，从而实现检测![[Pasted image 20261009134635.png]]
3. 工作流程：工作流程：红外发生二极管发射红光，当没有障碍的时候，U5接收到的反射的光比较少，则产生电流较小，电阻两端的电压比较大，当遇到障碍的时候就会反射回红外光时候，U5的电流就会变大，从而使整个电路的电流变大，电流变大后，电阻消耗的电压变多，从而产生较大的压降，而mcu就是通过检测通过电阻后的电压的多少来判断的

# 3.4 H桥电机驱动电路设计
1. H桥基本原理：![[Pasted image 20261009141629.png]]
	- 电机通上不同方向电流：正向正转，反向反转，从而控制电机的正反转
	- AD闭合，BC断开电机正转，相反则反转
	- AC或BD闭合 处于刹车状态 电机惯性转动产生的电势将被短路，形成阻碍运动的反电势，形成“刹车“作用
	- 当开关A,B,C和C四个开关都断开时候，认为电机处于“惰行”状态，电机惯性产生的电势无法形成电路，从而不会产生阻碍运动的反电势
