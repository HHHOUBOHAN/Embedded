# 低电平复位
1. 上电瞬间：
	- 状态：电容两端电压不能突变，上电瞬间电容相当于一根导线（短路）
	- 电压：电容下端接地（GND），上电瞬间相当于短路到地，直接把这根“导线”接到了RST引脚，此时 **RST = 0V，也就是低电平**。
	- 芯片状态：芯片检测到低电平（通常为有效复位电平），进入复位状态。
	- 电流方向：此时有巨大充电电流，方向是`VCC -> 电阻 -> RST -> 电容 -> GND`
2. 充电过程：
	- 状态：电容开始充电，两端电压开始升高。
	- 关键变化：ST引脚的电压 = 电容两端的电压。（因为电容下端是GND，RST接在电容上端）。
	- 电压：因为电容电压在不断升高，所以 **RST引脚的电压也在不断升高**。
	- 电流方向：依然是 `VCC -> 电阻 -> RST -> 电容 -> GND`，但电流越来越小
	- 芯片状态：RST电压还在复位阈值以下，芯片仍在复位
3. 充满电后：
	- 状态：电容充满电（电压达到VCC），相当于**断路（开路）**
	- 电流：**I = 0，没有电流了**
	- 电压：因为电路中没有电流，上面这个电阻两端的电压降 U = I × R = 0V
	- 被拉高：既然电阻没有压降（**电流流过电阻时，电阻两端的电位差**），RST引脚就被这个电阻直接“拽”到了VCC的电位，即 **RST = VCC（高电平）**
	- 芯片状态：芯片检测到高电平，复位结束，**开始正常工作**

# 高电平复位
1. 上电瞬间
	- 状态：电容两端电压不能突变，上电瞬间电容相当于一根导线（短路）
	- 电压：VCC（高电平）直接这根“导线”，到达RST引脚，此时**RST = VCC，也就是高电平**。
	- 芯片状态：芯片检测到高电平，进入复位状态
	- 电流方向：此时有巨大的充电电流，方向是 `VCC -> 电容 -> RST -> 电阻 -> GND`
2. 充电过程
	- 状态：电容开始充电,两端电压开始升高
	- 关键变化：RST引脚的电压 = VCC电压 - 电容两端的电压。
	- 电压：因为电容电压在不断升高，所以 **RST引脚的电压在不断降低**
	- 电流方向：依然是 `VCC -> 电容 -> RST -> 电阻 -> GND`，但电流越来越小
	- 芯片状态:RST电压还在阈值以上，芯片仍在复位
3. 充满电后
	- 状态: 电容充满电（电压达到VCC），相当于**断路（开路**)
	- 电流: **I = 0，没有电流了**
	- 电压：路中没有电流，下面这个电阻两端的电压降 U = I × R = 0V
	- 被拉低：既然电阻没有压降，RST引脚就被这个电阻直接“拽”到了GND的电位，即 **RST = 0V（低电平）**
	- 芯片状态：芯片检测到低电平，复位结束，**开始正常工作**。

# 低电平按键复位
1. 平时
	- 状态：按键K6断开，电容C12已经充满电（相当于断路）。整个回路没有电流（I = 0）
	- 电压：上拉电阻没有压降，RST引脚被R12直接“拽”到了3.3V
	- 结果：**RST = 3.3V（高电平）**。芯片处于正常工作状态
2. 按下按键
	- 状态：把RST引脚直接短路到了GND（地）。同时，C12通过按键迅速放电
	- 电流：3.3V -> R12 -> RST -> K6 -> GND，形成了一条新的回路，有了电流。
	- 电压：虽然R12在努力往上拉，但按键K6直接把RST按死在了地上（0V）。此时RST引脚对地的电压是按键两端的电压，按键是导线，电压为0。
	- 结果：**RST = 0V（低电平）**。芯片检测到低电平，进入复位状态。
	- 按键作用强行拉低，不论上拉电阻如何拉，按键直接把线接地了，RST只能变成低电平。
3. 松开按键
	- **状态**：按键K6断开，RST到GND的短路被切断了
	- **电流**：电流重新回到 `3.3V -> R12 -> RST -> C12` 这条路上。因为刚才按下按键时C12被放了一点电，此时电源3.3V会再次通过R12给C12充电（有充电电流
	- **电压**：在充电过程中，RST的电压慢慢升高；当C12充满电后，电流归零，R12没有压降，RST引脚被重新“拽”回到3.3V
	- 结果：**RST = 3.3V（高电平）**。芯片检测到高电平，复位结束，重新开始工作

# 高电平按键复位
1. 平时（按键没按下）
	- 状态：按键断开，电容充满电，整个回路没有电流
	- 电压：没有电流，电阻没有压降，RST引脚被R13直接“拽”到了GND（0V）。
	- 结果：**RST = 0V（低电平）**。芯片处于正常工作状态
2. 按下按键
	- 按键闭合，把RST引脚直接短路到了3.3V。同时，C13通过按键迅速充电
	- 电流：3V -> K6 -> RST -> R13 -> GND，形成了一条新的回路，有了电流
	- 电压：电阻虽然在下拉，按键直接把RST按死在了3.3V上，此时RST引脚对地的电压是按键两端的电压，按键是导线，电压为3.3V。
	- 结果：**RST = 3.3V（高电平）**。芯片检测到高电平，进入复位状态
3. 松开按键
	- 按键断开，RST到3.3V的短路被切断了
	- 此时C13开始放电，电流方向是 `C13正极 -> RST -> R13 -> GND`因为刚才按下按键时C13被充了电，此时电容像个临时电源一样在放电。
	- 放电过程中，RST的电压从3.3V慢慢下降；当C13放完电后，电流归零，R13没有压降，RST引脚被重新“拽”回到GND（0V）。
	- 结果：**RST = 0V（低电平）**。芯片检测到低电平，复位结束，重新开始工作

# 压降
1. 压降：电流流过电阻时，电阻两端的电位差
2. 用水管来比喻：
	- 电压：水塔的水压
	- 电流：像水管里塞了一块海绵，水流过时会受到阻碍，水压会下降
	- 压降：就是海绵前端和后端的水压差
	- 公式：压降 U = 电流 I × 电阻 R
	- **如果没有水流（电流 I = 0），海绵两端的水压就是一样的，压降就是 0**、
# 拉高，拉低
- **第一步**：电容充满，变成断路。
    
- **第二步**：因为断路，整个回路没有电流（I = 0）。
    
- **第三步**：因为电流是0，所以电阻两端的“压降”是 0V（U = 0 × R = 0）。
    
- **第四步**：既然电阻上没有压降，电阻就像一根普通的导线，把 RST 引脚直接连到了它另一端（VCC 或 GND）。
    
- **第五步**：所以 RST 引脚被“强行”赋予了它另一端连接的电位。连到 VCC 就叫“被拉高”，连到 GND 就叫“被拉低”
