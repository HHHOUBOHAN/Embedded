# 简介
1. 金属氧化物半导体场效应管（由电压控制的电子开关）
2. 普通开关
```
24V ─────/ ───── 负载
          ↑
        机械开关
```
3. MOS不需要机械动作，通过电压来实现开关
```
Gate→控制→MOS→开/关
```
4. 分类
	- N沟道（增强型 耗尽型） NMOS
	- P沟道（增强型 耗尽型）  PMOS

# 引脚含义
1. 常见的MOS管通常有三个引脚

| 符号  | 英文     | 中文  | 主要作用 |
| --- | ------ | --- | ---- |
| G   | Gate   | 栅极  | 控制   |
| D   | Drain  | 漏极  | 主电流端 |
| S   | Source | 源极  | 主电流端 |
2. 宗旨: G负责控制，D和S负责让电流通过’
# 导通原理
1. 把电流想象成水，Gate 就像一个控制阀
```
水流
↓↓↓↓↓↓

D ─────────── S
       │
       │
      开关
       ↑
      Gate
```
2. Gate不给合适的控制电压,电流通过不了
```
Gate
 ↓
阀门关闭

D ──────X────── S
```
3. Gate不给合适的控制电压
```
Gate
 ↓
阀门打开

D ───────────── S
       ↑
     电流通过
```
4. MOS管的核心：通过栅极的电压控制来实现源极和漏极的导通程度
# NMOS
1. 简单理解为：Gate电压高，容易打开，即VGS越大，越容易导通
2. 核心公式：`VGS = VG - VS` 栅极电压-源极电压
3. 作用：通过stm32控制MOS,MOS控制大电流，从而实现工作，即**小电流控制大电流**
# PMOS
1. 简单理解：Gate电压低，容易打开。VGS 越小，越容易导通
2. 举例：Source = 24V，Gate = 24V 得到VGS为0  ，不导通
3. 但是如果Source = 24V，Gate = 12V  得到VGS为-12  ，导通
