# 肖特基二极管
1. 二极管规则：正常导通时，电流从 A（阳极）流向 K（阴极）。
# 三极管
1. 三极管：用小电流控制大电流  类似于水流 ![[Pasted image 20260820162434.png]]
2. NPN型三极管:
	 - 右面的N是大电流输入端，命名为集电极，缩写符号是c
	 - 中间用于控制的P型半导体命名为基极，缩写符号是b
	 - 左面的N是大电流输出端，命名为发射极，缩写符号是e
3. NPN型三极管常用型号：8050 9013 9014 9018![[Pasted image 20260820163121.png]]
