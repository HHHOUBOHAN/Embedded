# 运算放大器
1. 双输入单输出结构
2. 同相输入端Vp 反向输入端Vn 输出端Vo                                                                              ![[Pasted image 20261009124621.png]]
3. 功能：$\[ \boxed{(V_P-V_N)\times10^5=V_O} \]$  放大电路
4. 运算放大器是需要单独供电的，当Vp小于Vn，接上多少V的电压， 输出端Vo就是输出多少V电压（输出会向正方向饱和，接近正电源对应的输出上限），当Vp小于Vn，计算得到一个负数，就会变成整个系统当中最低电位，因为接地，所以输出0V![[Pasted image 20261009125029.png]]
5. 输入阻抗非常大，导致电流无法输入到Vn中，类似于断开，但是并不是断开，专业名词叫做虚断![[Pasted image 20261009130147.png]]
6. 虚短：在深度负反馈的前提下， 运算放大器输入虚短
7. 反向放大器![[Pasted image 20261009131323.png]]
	 - 深度负反馈：同相端电压等于反相端电压
