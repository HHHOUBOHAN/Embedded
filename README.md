# 🚀 Embedded - 嵌入式系统学习与工程实践

> 欢迎来到我的嵌入式系统学习与工程实践仓库！这里记录了我从底层硬件设计到上层软件开发的全过程。内容涵盖技术栈梳理、实战项目复盘以及个人的日常思考。（持续更新中...）

## 📁 仓库目录结构

为了方便检索，仓库按照软件、硬件及工程化模块进行了分类整理：

### 💻 软件与系统生态
| 目录/文件 | 说明 |
| :--- | :--- |
| 📂 **`软件`** | 通用软件架构设计、算法、C/C++ 基础及编程规范 |
| └─ 📂 *报错调试* | 常见编译/运行报错分析与调试技巧（如 HardFault 分析） |
| └─ 📂 *C语言* | C 语言核心语法、指针、内存管理等进阶笔记 |
| └─ 📂 *FreeRTOS* | 实时操作系统内核源码分析、任务调度与移植记录 |
| └─ 📂 *QT&LVGL* | 上位机 QT 开发与嵌入式 GUI (LVGL) 学习记录 |
| └─ 📂 *STM32* | STM32 单片机基础外设、寄存器/标准库/HAL库开发 |
| 📂 **`通信`** | 串口、I2C、SPI、CAN、网络等通信协议与实战 |
| 📂 **`中间件`** | 常用第三方库、协议栈（如 FatFs、LwIP 等）的移植与使用 |

## 🛠️ 技术栈 (Tech Stack)

- **微控制器 (MCU)**: STM32 系列
- **实时操作系统 (RTOS)**: FreeRTOS
- **图形界面**: QT / LVGL
- **开发语言**: C / C++
- **开发工具**: Keil MDK / STM32CubeMX / VS Code / Git
- **知识管理**: Obsidian (Markdown)
