# 🚀 Embedded - 嵌入式系统学习与实践（更新中）

欢迎来到我的嵌入式系统学习与工程实践仓库！这里记录了我从底层硬件设计到上层软件开发的过程（更新中），包含了技术栈的梳理、实战项目、以及个人的学习思考。

## 🛠️ 技术栈 (Tech Stack)

*   **微控制器 (MCU)**: STM32 系列
*   **实时操作系统 (RTOS)**: FreeRTOS
*   **硬件设计**: PCB Layout (如 Altium Designer, 嘉立创EDA 等)
*   **开发语言**: C / C++
*   **开发工具**: Keil MDK / STM32CubeMX / VS Code (配合插件)
*   **知识管理**: Obsidian (Markdown)
