# 电源网络名称
|标记|含义|是否说明电压|
|---|---|---|
|`VCC`|正电源|没说明是几伏|
|`+3V3`|3.3V正电源|明确是3.3V|
|`+5V_SYS`|系统5V电源|明确是5V|
|`+24V_SYS`|系统24V电源|明确是24V|


| 电源用途       | 统一网络名称      | 说明                 |
| ---------- | ----------- | ------------------ |
| 外部24V输入    | `+24V_IN`   | 电源插座刚输入、保护电路之前     |
| 保护后的24V总电源 | `+24V_SYS`  | 经过保险、反接和浪涌保护之后     |
| 灯泡/水泵24V电源 | `+24V_LOAD` | 专门供给24V灯泡或以后两线水泵   |
| 系统5V电源     | `+5V_SYS`   | DC/DC输出，供4G板、部分传感器 |
| 系统3.3V电源   | `+3V3`      | 供STM32、OLED和数字逻辑   |
| 模拟3.3V电源   | `+3V3_A`    | 供STM32的VDDA及模拟采集电路 |
| 公共地        | `GND`       | 整个低压系统的电气参考地       |
★ `VCC` 只表示泛指电源，不说明具体电压。本项目原理图应使用 `+24V_SYS`、`+5V_SYS`、`+3V3` 等明确名称。
