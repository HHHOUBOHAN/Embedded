# Keil 中添加自定义 Templates 代码模板

## 1. Templates 是什么？

Keil 里面的 **Templates** 是代码模板窗口。

作用是：

> 把常用代码片段保存起来，以后需要时双击模板，就可以自动插入到当前代码位置。

适合保存一些经常重复写的代码，比如：

```c
HAL_Delay(500);
printf("value = %d\r\n", value);
HAL_GPIO_WritePin(BEEP_GPIO_Port, BEEP_Pin, GPIO_PIN_SET);
````

---

## 2. 打开 Templates 窗口

在 Keil 顶部菜单中选择：

```text
View -> Templates
```

然后右侧或左侧会出现 **Templates** 窗口。

常见默认模板有：

```text
#define
#if
#include
for
if
while
switch
function
struct
```

---

## 3. 添加自己的模板

在 **Templates** 窗口中操作：

1. 在模板列表空白处 **右键**
    
2. 选择：
    

```text
Configure Templates
```

3. 进入配置窗口后，找到：
    

```text
Text File Types
```

4. 选择文件类型，一般选择：
    

```text
C/C++ Source File
```

或者类似：

```text
*.c / *.h
```

5. 在 **Templates** 那一栏点击右上角的：
    

```text
+
```

6. 输入模板名字，例如：
    

```text
adc_read
```

7. 在下面的 **Text** 区域写入要保存的代码
    
8. 点击：
    

```text
OK / Apply
```

---

## 4. 添加 ADC 读取模板示例

模板名字：

```text
adc_read
```

模板内容：

```c
HAL_ADC_Start(&hadc1);
HAL_ADC_PollForConversion(&hadc1, 100);
adc_value = HAL_ADC_GetValue(&hadc1);
HAL_ADC_Stop(&hadc1);
```

以后使用时，双击 `adc_read`，这段代码就会自动插入。

---

## 5. 添加串口打印模板示例

模板名字：

```text
uart_printf
```

模板内容：

```c
printf("value = %d\r\n", value);
```

适合调试时快速打印变量。

---

## 6. 添加蜂鸣器控制模板示例

模板名字：

```text
beep_on
```

模板内容：

```c
HAL_GPIO_WritePin(BEEP_GPIO_Port, BEEP_Pin, GPIO_PIN_SET);
```

模板名字：

```text
beep_off
```

模板内容：

```c
HAL_GPIO_WritePin(BEEP_GPIO_Port, BEEP_Pin, GPIO_PIN_RESET);
```

---

## 7. 模板中的光标位置

Keil 模板中可以使用 `|` 表示插入模板后光标停留的位置。

例如：

```c
printf("|");
```

插入后，光标会停在双引号里面。

再比如：

```c
HAL_Delay(|);
```

插入后光标会停在括号里面，方便直接输入延时时间。

---

## 8. 使用模板

使用步骤：

1. 把光标放到代码中想插入的位置
    
2. 打开 **Templates** 窗口
    
3. 找到自己的模板
    
4. 双击模板名称
    
5. 代码自动插入
    

---

## 9. Templates 适合放什么？

适合放一些短的、经常重复写的代码片段，例如：

```c
HAL_Delay(500);
```

```c
printf("value = %d\r\n", value);
```

```c
HAL_ADC_Start(&hadc1);
HAL_ADC_PollForConversion(&hadc1, 100);
adc_value = HAL_ADC_GetValue(&hadc1);
HAL_ADC_Stop(&hadc1);
```

```c
HAL_GPIO_WritePin(BEEP_GPIO_Port, BEEP_Pin, GPIO_PIN_SET);
```

---

## 10. Templates 不适合放什么？

如果是一整个功能函数，不建议只放在模板里反复复制。

比如：

```c
void BEEP_On(void);
void BEEP_Off(void);
float ADC_GetVoltage(void);
```

这种更推荐封装成 `.c` 和 `.h` 文件。

例如：

```text
hardware/
├── beep.c
├── beep.h
├── adc_app.c
└── adc_app.h
```

然后在 `main.c` 里面：

```c
#include "beep.h"
#include "adc_app.h"
```

使用时直接调用：

```c
BEEP_On();
voltage = ADC_GetVoltage();
```

---

## 11. 总结

Templates 的作用：

```text
保存常用代码片段，双击即可快速插入。
```

适合：

```text
短代码、调试代码、常用 HAL 函数调用。
```

不适合：

```text
完整功能模块、复杂业务逻辑。
```

完整功能最好写成：

```text
.c 文件：写函数实现
.h 文件：写函数声明
main.c：include 后调用
```

一句话记忆：

> 短代码放 Templates，完整功能封装成 .c/.h 文件。
