## ST-Link最核心的4根线（SWD模式）
- **🔴3.3V接3.3V**
    
    - **说人话：**这是**“供电线”**。ST-Link从电脑USB吸取能量，转换成3.3伏特喂单片机。接上这条根线，单片机板上的电源灯（一般是红灯）就会亮起。
        
- **⚫ GND 接 GND**
    
    - **说人话：**这是**“接地线”**。有出就得有进，当前从 3.3V流出，必须从GND流回来，构成一个完整的循环。这根线极其重要，必须接牢！
        
- **🔵 SWDIO 接 DIO (有些板子上印着 SWDIO)**
    
    - **说人话：**D 就是 Data（数据）。这是**“输入数据输出线”**。你的代码010101的信号，就是顺着这根线传进单片机里的。
        
- **🟢 SWCLK接DCLK（有些板子上印着SWCLK）**
    
    - **说人话：**CLK即时钟（时钟）。这是**“打节拍的线”**。因为数据传输得极快，两边必须有一个指挥家打着相同的节拍（比如“一二一、一二一”），才不会把数据传错。

# 10针调试接口（2×5）上下排引脚定义与接线说明

## 一、接口排列方式

该接口为 **双排5针（2行 × 5列）**，常见于 ST-Link、J-Link OB 或 STM32/STM8 开发板。

- **上排**：靠近板边（或标有 “1” 的引脚侧）
- **下排**：内侧

## 二、上下排引脚功能对照表

| 引脚序号 | 上排（靠近板边） | 下排（内侧） |
| :------: | :--------------: | :----------: |
| 1 | RST（复位） | SWCLK（SWD时钟） |
| 2 | SWIM（STM8 调试） | SWDIO（SWD数据） |
| 3 | GND | GND |
| 4 | 3.3V | 3.3V |
| 5 | 5.0V | 5.0V |

> **注意**  
> - **SWIM** 是 STM8 系列单片机专用的单线调试接口。  
> - **SWCLK / SWDIO** 是 STM32 及其他 ARM Cortex-M 芯片的 SWD 调试接口。  
> - 上下排的 **GND、3.3V、5.0V** 在电路板内部通常是连通的，因此电源与地上下排没有本质区别。

## 三、核心区别与使用场景

| 适用芯片 | 使用哪一排 | 必须连接的信号 | 可选电源 | 忽略的信号 |
| :------: | :--------: | :------------: | :------: | :---------: |
| **STM32** 或其他 ARM | **下排** | SWCLK, SWDIO, GND | 3.3V（若板卡不独立供电） | SWIM, RST, 5.0V |
| **STM8** | **上排** | SWIM, RST, GND | 3.3V 或 5.0V（视芯片电压而定） | SWCLK, SWDIO |

## 四、接线示例（以 STM32 + ST-Link 调试器为例）

### 1. 调试器与目标板连接表

| ST-Link 引脚 | 目标板接口（**下排**） |
| :----------: | :--------------------: |
| SWCLK | SWCLK |
| SWDIO | SWDIO |
| GND   | GND   |
| 3.3V  | 3.3V（可选，见下文） |

### 2. 重要注意事项

- **电源选择**：STM32 一般使用 **3.3V**，不要同时接 3.3V 和 5.0V。
- **独立供电**：如果目标板已由外部电源供电，调试器**只接 SWCLK、SWDIO、GND**，切勿再接入 3.3V 或 5.0V，以免烧毁调试器或目标板。
- **复位引脚（RST）**：SWD 调试通常不需要硬件复位，可不接 RST。若遇到连接问题，可将调试器的 RST 连至目标板的上排 RST 引脚。
- **STM8 用户**：请使用上排的 SWIM + RST，调试器需支持 SWIM 模式（如 ST-Link/V2）。

## 五、如何快速确定上排与下排

1. 查看接口旁边的 **丝印小圆点** 或 **数字 “1”**，该处即为 **第1脚**。
2. 常见的 2×5 排针：
   - 第1脚 = 上排最左
   - 第2脚 = 下排最左
3. 用万用表 **蜂鸣档** 测任意 GND 引脚（与板子大面积覆铜或外壳相通），即可定位整排引脚顺序。

### 4. 烧录器接线

ST-Link与J-Link选其一，我们的标准开发套件里有一个ST-Link。

ST-Link需要用杜邦线与开发板连接，NRST引脚可以在单片机进入休眠状态时进行唤醒，如果单片机进入休眠状态，需要接NRST引脚再进行烧录。

J-Link则是排线设计，直接接入即可。
