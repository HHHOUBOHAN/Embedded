# 重定向

```c
#include "stdio.h"
int fputc(int ch, FILE *f)
{
 
  HAL_UART_Transmit(&huart3, (uint8_t *)&ch, 1, 0xFFFF);
  return ch;

}
```

1. `HAL_UART_Transmit(&huart3, (uint8_t *)&ch, 1, 0xFFFF);`
    `HAL_UART_Transmit(串口句柄, 数据指针, 数据长度, 最大超时时间);`
    第一是串口号 通过cubmax配置得出
    `(uint8_t *)&ch`
    取 `ch` 的**地址** 把这个地址**强制转换成 HAL 库要求的指针类型**
    强制转换成指向 uint8_t 类型的指针 因为这个发送的时候就是发送的uint8_t
