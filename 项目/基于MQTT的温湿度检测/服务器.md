# 统一配置
## MQTT服务器
```
服务器IP：81.70.187.191

STM32 / MQTTX TCP端口：1883
网页 WebSocket端口：9001

普通MQTT协议：MQTT 3.1.1
TLS：关闭
Keep Alive：60秒
QoS：0
```

## 三个客户端身份统一 

| 客户端     | MQTT Client ID     | 用户名   | 密码    | 作用     |
| ------- | ------------------ | ----- | ----- | ------ |
| STM32设备 | STM32_TEMP_FAN_001 | stm32 | stm32 | 设备上传数据 |
| MQTTX测试 | MQTTX_PC_001       | admin | admin | 电脑调试   |
| 网页      | WEB_TEMP_FAN_001   | web   | web   | 网页配置   |

- `STM32_TEMP_FAN_001` 写进 STM32 的 `network_config.c`
- `MQTTX_PC_001` 填在 MQTTX 界面
- `WEB_TEMP_FAN_001` 写在网页 JavaScript 中

### 文件配置
#### 用户创建
文件是否存在
```
sudo ls -l /etc/mosquitto/passwd
```

用户创建
```
sudo mosquitto_passwd /etc/mosquitto/passwd stm32
```
####  /etc/mosquitto/passwd
1. 密码文件权限问题
```
所有者：mosquitto 所属组：mosquitto 权限：600
```
- mosquitto用户：可读、可写 
- 其他所有用户：不可读、不可写
- root仍然具有系统最高权限，需要时照样能够维护这个文件
#### /etc/mosquitto/mosquitto.conf
1. **Mosquitto Broker的总配置文件**
```
  开哪些端口；
  1883使用普通MQTT；
  9001使用WebSocket；
  是否允许匿名用户；
  用户密码文件放在哪里；
  ACL权限文件放在哪里；
  是否保存离线数据；
  日志输出到哪里。
```
1. 权限:
2. 文件内容
```
# Mosquitto 主配置：TEMP-FAN 项目

user mosquitto

# 消息持久化
persistence true
persistence_location /var/lib/mosquitto/

# 日志输出到 systemd journal
log_dest stdout
log_type error
log_type warning
log_type notice
log_type information
connection_messages true
log_timestamp true

# 1883和9001统一使用账号密码及ACL
per_listener_settings false
allow_anonymous false

# 用户密码文件
password_file /etc/mosquitto/passwd

# Topic权限文件
acl_file /etc/mosquitto/acl

# STM32和MQTTX：普通MQTT TCP
listener 1883 0.0.0.0
protocol mqtt

# 网页：MQTT over WebSocket
listener 9001 0.0.0.0
protocol websockets
```


####  /etc/mosquitto/acl
1. 访问控制列表
```
  发布哪个Topic；
  订阅哪个Topic；
  哪些Topic完全不能访问。
```
1. 权限:
2. 文件内容
```
# STM32真实设备
# 上传状态、接收控制命令、上传执行应答
user stm32
topic write temp-fan/TEMP-FAN-001/status
topic read temp-fan/TEMP-FAN-001/command
topic write temp-fan/TEMP-FAN-001/ack


# MQTTX调试客户端
# 对该设备的全部Topic具有读写权限
user admin
topic readwrite temp-fan/TEMP-FAN-001/#


# 网页客户端
# 查看状态、发送控制、查看执行应答
user web
topic read temp-fan/TEMP-FAN-001/status
topic write temp-fan/TEMP-FAN-001/command
topic read temp-fan/TEMP-FAN-001/ack
```
#### 如何工作
```
客户端连接81.70.187.191
        ↓
mosquitto.conf确认端口和协议
        ↓
passwd检查用户名和密码
        ↓
acl检查Topic读写权限
        ↓
允许发布或订阅
```
