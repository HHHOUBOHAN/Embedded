 3. 工作过程
 ```
 +5V
 │
 ├── 输入滤波电容
 │
 ▼
AMS1117-3.3 的 VIN
 │
 │ 芯片把5V降低到3.3V
 ▼
AMS1117 的 VOUT
 │
 ├── 输出滤波电容
 │
 ▼
稳定的3.3V
 ```
 4. 两端电容作用
	 -  左边输入电容的作用
		 - 10μF 电容 
			- 电源缓慢波动
			- 低频干扰
			- 突然用电时的电流补充
			- 输入电压瞬间下跌
		- 100nF 电容
			- 高频尖峰
			- 数字电路产生的高频噪声
			- 电源线上的快速干扰
		- 两个电容并联并不重复，因为它们处理的干扰频率不同：
			- 10μF：处理较慢、较大的波动
			- 100nF：处理很快、很尖的高频干扰

## 复位电路
1.  原理图                                                 ![[Pasted image 20260708143258.png]]
2. 电路等效：
```
              3.3V
                │
             R3 10kΩ
                │
                ├──────── NRST → 单片机复位脚
                │
                ├── SW1 ───── GND
                │
                └── C9 0.1μF ─ GND
```
3. 平时没有按按键
	- SW1是常开按键，平时内部断开：NRST ──×── GND
	- 这时GND不能通过按键影响NRST。
	- R3会把NRST拉到3.3V：3.3V→R3→NRST
	- NRST ≈ 3.3V 单片机正常运行
	- R3因此叫作：上拉电阻（把一个节点默认拉到高电平）
4. 按下按键时
	- 按下SW1以后，开关内部接通：NRST ───── SW1 ───── GND
	- 此时NRST几乎直接接到GND：NRST ≈ 0V
	- 单片机检测到NRST为低电平，就进入复位状态。
	- 此时完整电流路径为：3.3V→R3 10kΩ→SW1→GND
	- 此时电阻作用时限流，防止电流过大 ，温度过高，烧坏元器件
5. 松开按键时
	- 松开按键后，SW1重新断开：NRST ──×── GND
	- 此时R3重新把NRST拉到3.3V:3.3V → R3 → NRST
	- NRST由低电平恢复到高电平,单片机退出复位,程序重新从头开始运行
