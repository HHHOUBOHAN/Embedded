问题已经定位得很明确了：**不是阈值生效慢，而是温度阈值根本没有成功写进单片机。**

你截图里其实有两条不同结果：

```text
设备应答成功：humidityMax=89
设备应答失败：error=invalid_temp
```

也就是说：

```text
湿度阈值 89%     已经生效
温度阈值 50.0℃  设置失败
```

当前温度是 `28.3℃`，设备仍使用原来的较低温度阈值，所以单片机继续上报：

```json
"alarm": 1,
"fan": 1
```

网页收到真实状态后，自然继续显示“报警”和风扇100%。

## 为什么温度设置失败

网页现在发送的是：

```javascript
publishCommand(`tempMax=${tempLimit.toFixed(1)}`, "thresholdFeedback");
```

当输入50℃时，实际发送：

```text
tempMax=50.0
```

但单片机 `remote_control.c` 中使用的是：

```c
strtol(text, &end, 10);
```

`strtol()`只解析整数。它解析到：

```text
50
```

后面还剩：

```text
.0
```

于是这段判断失败：

```c
if ((*end != '\0') ||
    (parsed < minimum) ||
    (parsed > maximum))
{
    return 0U;
}
```

最终回复：

```text
error=invalid_temp
```

湿度发送的是：

```text
humidityMax=89
```

没有小数点，所以能够成功。

# 阈值到底什么时候生效

完整流程是：

```text
网页发送命令
→ STM32收到command主题
→ RemoteControl_Process解析
→ AppControl_SetTemperatureLimit
→ 重新判断报警
→ 更新LED、蜂鸣器、风扇
```

使用你刚替换的阈值同步修复版后，只要命令解析成功，设置接口就会立即重新判断报警并刷新硬件，不用切页面，也不用等待重启。原来的公开阈值接口位于 `AppControl_SetTemperatureLimit()` 和 `AppControl_SetHumidityLimit()`。

但这一次温度命令停在了：

```text
RemoteControl_Process解析失败
```

所以根本没有进入 `AppControl_SetTemperatureLimit()`。

# 最合适的修改方法

网页本身支持：

```html
step="0.5"
```

按键也支持每次调节 `0.5℃`，所以不建议把网页强行改成整数。应修改 **`remote_control.c`**，让单片机支持：

```text
tempMax=50
tempMax=50.0
tempMax=28.5
```

## 第一处：增加温度解析函数

放在原来的 `RemoteControl_ParseValue()` 后面：

```c
static uint8_t RemoteControl_ParseTemperatureX10(
    const char *text,
    int16_t *value_x10)
{
    const char *position;
    long integer_part = 0L;
    long decimal_part = 0L;
    long result;
    int8_t sign = 1;

    if ((text == NULL) ||
        (value_x10 == NULL) ||
        (*text == '\0'))
    {
        return 0U;
    }

    position = text;

    if (*position == '-')
    {
        sign = -1;
        position++;
    }

    if ((*position < '0') || (*position > '9'))
    {
        return 0U;
    }

    while ((*position >= '0') && (*position <= '9'))
    {
        integer_part =
            integer_part * 10L +
            (long)(*position - '0');

        position++;
    }

    if (*position == '.')
    {
        position++;

        if ((*position < '0') || (*position > '9'))
        {
            return 0U;
        }

        decimal_part = (long)(*position - '0');
        position++;
    }

    if (*position != '\0')
    {
        return 0U;
    }

    result =
        (long)sign *
        (integer_part * 10L + decimal_part);

    if ((result < -450L) || (result > 1300L))
    {
        return 0U;
    }

    *value_x10 = (int16_t)result;
    return 1U;
}
```

## 第二处：替换温度命令处理

找到原来的：

```c
else if(strncmp(command,"tempMax=",8) == 0)
{
    if (RemoteControl_ParseValue(
            command + 8,
            -45L,
            130L,
            &value) == 0U)
    {
        (void)snprintf(
            ack,
            ack_size,
            "error=invalid_temp");

        return 1U;
    }

    AppControl_SetTemperatureLimit(
        (int16_t)(value * 10L));
}
```

替换为：

```c
else if(strncmp(command,"tempMax=",8) == 0)
{
    int16_t temperature_x10;

    if (RemoteControl_ParseTemperatureX10(
            command + 8,
            &temperature_x10) == 0U)
    {
        (void)snprintf(
            ack,
            ack_size,
            "error=invalid_temp");

        return 1U;
    }

    AppControl_SetTemperatureLimit(
        temperature_x10);
}
```

网页的这一行可以保持不变：

```javascript
publishCommand(
    `tempMax=${tempLimit.toFixed(1)}`,
    "thresholdFeedback"
);
```
