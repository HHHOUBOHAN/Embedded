# 一、这些“连接”分别是干什么的

你的腾讯云服务器里面，现在实际上有这些东西：

```text
腾讯云轻量应用服务器
│
├─ OpenCloudOS：服务器操作系统
│
├─ 宝塔面板：管理服务器的网页工具
│
├─ Nginx：以后运行网站
│
└─ Mosquitto：运行 MQTT 服务
```

## 1. 宝塔连接

宝塔地址：

```text
https://81.70.187.191:23579/hbhhbh
```

用途是管理服务器，例如：

- 管理网站；
    
- 管理文件；
    
- 查看系统状态；
    
- 使用服务器终端；
    
- 安装软件。
    

**宝塔不是 MQTT 服务器。**

## 2. Mosquitto连接

Mosquitto监听：

```text
81.70.187.191:1883
```

用途是转发物联网消息。

例如：

```text
STM32发布温度
        ↓
Mosquitto收到消息
        ↓
MQTTX订阅后显示温度
```

Mosquitto是独立运行的系统服务，不需要一直打开宝塔页面。

## 3. MQTTX连接

MQTTX安装在你的Windows电脑上，用来测试MQTT。

它相当于一个“物联网调试助手”，可以：

- 连接Mosquitto；
    
- 订阅STM32上传的数据；
    
- 给STM32发送控制命令；
    
- 检查主题和JSON消息；
    
- 排除服务器或单片机问题。
    

## 4. STM32与ESP8266连接

STM32本身不能直接联网，所以由ESP-01S负责网络连接：

```text
STM32
  │ USART1串口
  │ AT+MQTTCONN等命令
  ▼
ESP-01S
  │ Wi-Fi
  ▼
腾讯云Mosquitto
```

ESP8266的官方MQTT AT固件使用：

```text
AT+MQTTUSERCFG
AT+MQTTCONN
AT+MQTTSUB
AT+MQTTPUB
```

其中方案值 `1` 代表普通MQTT TCP，`AT+MQTTCONN` 最后一个参数设为 `1` 代表启用自动重连。([Espressif Systems](https://docs.espressif.com/projects/esp-at/zh-cn/release-v2.2.0.0_esp8266/AT_Command_Set/MQTT_AT_Commands.html "MQTT AT Commands — ESP-AT 用户指南  文档"))

## 5. 腾讯云防火墙连接

腾讯云防火墙位于服务器最外层：

```text
MQTTX或ESP8266
        ↓
腾讯云防火墙
        ↓
服务器系统
        ↓
Mosquitto
```

即使Mosquitto已经运行，如果腾讯云防火墙设置：

```text
1883 拒绝
```

外面的MQTTX和ESP8266也进不来。腾讯云官方说明，“允许”会放行访问，“拒绝”会直接丢弃数据包；规则冲突时，排在上面的规则优先。([腾讯云](https://cloud.tencent.com/document/product/1207/44577/ "轻量应用服务器 管理实例防火墙_腾讯云"))

# 二、第一阶段：更换MQTT密码

你刚才使用的是：

```text
用户名：hbh1
密码：hbh1
```

这个密码已经出现在聊天和终端命令中，而且过于简单。在开放公网1883之前先更改。

## 第1步：进入腾讯云黑色终端

看到：

```bash
[root@VM-0-13-opencloudos ~]#
```

输入：

```bash
mosquitto_passwd /etc/mosquitto/passwd hbh1
```

注意这次不要加 `-c`。

终端提示：

```text
Password:
Reenter password:
```

输入两遍新密码。

密码建议：

```text
12～24个字符
包含大小写字母、数字和下划线
不要包含双引号、逗号和反斜杠
```

因为密码后续需要放进ESP8266的AT命令中。

Mosquitto官方说明：修改已有用户密码时不加 `-c`；`-c` 会重新创建并覆盖现有密码文件。([Eclipse Mosquitto](https://mosquitto.org/documentation/authentication-methods/ "Authentication methods | Eclipse Mosquitto"))

## 第2步：重新设置权限并重启

依次执行：

```bash
chown mosquitto:mosquitto /etc/mosquitto/passwd
```

```bash
chmod 640 /etc/mosquitto/passwd
```

```bash
systemctl restart mosquitto
```

```bash
systemctl status mosquitto --no-pager -l
```

正常必须看到：

```text
Active: active (running)
```

Mosquitto密码文件需要能够被运行服务的 `mosquitto` 用户读取。([Eclipse Mosquitto](https://mosquitto.org/documentation/authentication-methods/ "Authentication methods | Eclipse Mosquitto"))

## 第3步：确认1883监听

执行：

```bash
ss -lntp | grep 1883
```

正常类似：

```text
LISTEN 0 100 0.0.0.0:1883
```

代表：

```text
Mosquitto正在监听所有网卡的1883端口
```

# 七、第六阶段：确定正式MQTT主题

后面不要继续长期使用：

```text
test/demo
```

正式项目使用三条主题：

```text
hbh0137/device01/status
hbh0137/device01/command
hbh0137/device01/ack
```

分别表示：

|主题|发送方向|用途|
|---|---|---|
|`status`|STM32 → MQTTX|上传温湿度、风扇和报警状态|
|`command`|MQTTX → STM32|下发模式、风扇、阈值命令|
|`ack`|STM32 → MQTTX|返回指令执行结果|

完整方向：

```text
STM32发布 status
      ↓
Mosquitto
      ↓
MQTTX订阅 status
```

```text
MQTTX发布 command
      ↓
Mosquitto
      ↓
ESP8266订阅 command
      ↓
STM32执行命令
      ↓
STM32发布 ack
      ↓
MQTTX收到 ack
```

# 九、第八阶段：修改ESP8266 MQTT登录代码

你原来的代码：

```c
(void)snprintf(command, sizeof(command),
               "AT+MQTTUSERCFG=0,1,\"%s\",\"\",\"\",0,0,\"\"\r\n",
               NETWORK_DEVICE_ID);
```

其中：

```c
"",""
```

表示用户名和密码都是空的。

但你的Mosquitto配置了：

```text
allow_anonymous false
```

所以空用户名、空密码一定会被拒绝。

## 修改为带用户名和密码

在 `MqttClient_Connect()` 开头选中云端配置：

```c
const NetworkMqttConfig_t *mqtt_config =
    &NETWORK_MQTT_CLOUD_CONFIG;
```

然后USERCFG改成：

```c
mqtt_state = MQTT_STATE_USERCFG;

(void)snprintf(command,
               sizeof(command),
               "AT+MQTTUSERCFG=0,1,"
               "\"%s\",\"%s\",\"%s\",0,0,\"\"\r\n",
               NETWORK_DEVICE_ID,
               mqtt_config->username,
               mqtt_config->password);

if (ESP8266_SendAT(command, "OK", 5000U) != HAL_OK)
{
    mqtt_state = MQTT_STATE_USERCFG_ERROR;
    return 0U;
}
```

这里的参数含义是：

```text
0                    LinkID
1                    MQTT普通TCP
NETWORK_DEVICE_ID    客户端ID
username             MQTT用户名
password             MQTT密码
0,0                  证书编号，当前不用
""                   WebSocket路径，当前不用
```

官方ESP8266 MQTT AT语法正是：

```text
AT+MQTTUSERCFG=<LinkID>,<scheme>,
"client_id","username","password",
<cert_key_ID>,<CA_ID>,"path"
```

并且单条AT命令总长度不能超过256字节。([Espressif Systems](https://docs.espressif.com/projects/esp-at/zh-cn/release-v2.2.0.0_esp8266/AT_Command_Set/MQTT_AT_Commands.html "MQTT AT Commands — ESP-AT 用户指南  文档"))

## 连接服务器代码

```c
mqtt_state = MQTT_STATE_CONNECTING;

(void)snprintf(command,
               sizeof(command),
               "AT+MQTTCONN=0,\"%s\",%u,1\r\n",
               mqtt_config->host,
               mqtt_config->port);

if (ESP8266_SendAT(command, "OK", 10000U) != HAL_OK)
{
    mqtt_state = MQTT_STATE_CONNECT_ERROR;
    return 0U;
}
```

最终ESP8266会发送类似：

```text
AT+MQTTCONN=0,"81.70.187.191",1883,1
```

最后的 `1` 表示断线后自动重连。([Espressif Systems](https://docs.espressif.com/projects/esp-at/zh-cn/release-v2.2.0.0_esp8266/AT_Command_Set/MQTT_AT_Commands.html "MQTT AT Commands — ESP-AT 用户指南  文档"))

## 订阅控制主题

```c
mqtt_state = MQTT_STATE_SUBSCRIBING;

(void)snprintf(command,
               sizeof(command),
               "AT+MQTTSUB=0,\"%s\",0\r\n",
               NETWORK_TOPIC_COMMAND);

if (ESP8266_SendAT(command, "OK", 5000U) != HAL_OK)
{
    mqtt_state = MQTT_STATE_SUBSCRIBE_ERROR;
    return 0U;
}
```

成功后：

```c
mqtt_connected = 1U;
mqtt_state = MQTT_STATE_ONLINE;
```
