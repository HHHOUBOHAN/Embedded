# 先看网页打开过程

你输入：

```
http://81.70.187.191
```

发生的是：

```
电脑浏览器
      |
      | HTTP请求
      |
      ↓
服务器80端口
      |
      |
    Nginx
      |
      |
返回网页文件
      |
      ↓
index.html
```

这里的80端口只负责：

> **把网页文件给浏览器**

例如：

服务器里面：

```
/www/wwwroot/tempfan

├── index.html
├── app.js
├── mqtt.js
└── style.css
```

浏览器请求：

```
index.html
```

Nginx返回：

```
网页界面
```

到这里结束。

**1883连接和9001连接的职责边界**

1. 1883 设备上传数据  **设备接收控制** 设备反馈
2. 9001 接收设备状态  发送控制命令 接收ACK

- **查看Topic**
- **找到订阅者并转发**
