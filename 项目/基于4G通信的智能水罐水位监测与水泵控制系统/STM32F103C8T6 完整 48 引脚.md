# 3. 你现在最应该关注的几个引脚

因为你正在设计你的整块板子，我建议先把这些标出来。

### ① SWD烧录/调试

```text
PA13 / Pin 34 → SWDIO
PA14 / Pin 37 → SWCLK
NRST / Pin 7  → RESET
```

所以：

```text
J_DEBUG
│
├── NRST  → Pin 7
├── GND
├── SWCLK → Pin 37
├── SWDIO → Pin 34
└── 3.3V
```

---

### ② BOOT0

```text
BOOT0 / Pin 44
```

建议：

```text
BOOT0
  │
  ├── 10kΩ → GND
  │
  └── 跳帽 → 3.3V
```

正常运行：

```text
BOOT0 = 0
```

---

### ③ USART1

这个以后非常可能给你的4G模块使用：

```text
PA9  / Pin 30 → USART1_TX
PA10 / Pin 31 → USART1_RX
```

也就是：

```text
STM32 PA9  ─────→ 4G RX
STM32 PA10 ←───── 4G TX
```

这个和你之前说的 **ML307C** 就可以对应起来。

---

### ④ USART2

```text
PA2 / Pin 12 → USART2_TX
PA3 / Pin 13 → USART2_RX
```

可以留给：

- USB-TTL
    
- GPS
    
- 其他串口模块
    

---

### ⑤ SPI1

如果后面你接屏幕/Flash等：

```text
PA4 → SPI1_NSS
PA5 → SPI1_SCK
PA6 → SPI1_MISO
PA7 → SPI1_MOSI
```

---

### ⑥ I²C

常用：

```text
PB6 → I2C1_SCL
PB7 → I2C1_SDA
```

适合：

- 温湿度传感器
    
- OLED
    
- IMU
    
- EEPROM
    

---

### ⑦ SPI2

```text
PB12 → NSS
PB13 → SCK
PB14 → MISO
PB15 → MOSI
```

---

# 4. 你这块板我建议先这样分配

按照你现在正在设计的项目，我会先预留：

```text
STM32F103C8T6

PA13 ── SWDIO
PA14 ── SWCLK
NRST ── 调试复位

PA9  ── 4G TX
PA10 ── 4G RX

PB6  ── I2C SCL
PB7  ── I2C SDA

PA5  ── SPI SCK
PA6  ── SPI MISO
PA7  ── SPI MOSI
PA4  ── SPI CS

PB12~PB15 ── 第二路SPI

PB0/PB1/其他GPIO
       ↓
传感器/接触器/状态控制
```

**注意：这只是接口资源规划，不是说所有这些功能必须同时使用。** STM32F103 的复用功能还涉及 AFIO 重映射，真正确定原理图之前要把你的全部外设一起规划，避免出现“两个模块抢同一个引脚”的问题。

如果你现在就是要开始画这块**STM32最小系统原理图**，下一步最好先把 **48个脚按“电源 / SWD / 晶振 / UART / I2C / SPI / GPIO”分类**，再决定每个外设具体占哪些脚。这样比直接一个模块一个模块往上接更不容易出现你之前遇到的引脚冲突。
