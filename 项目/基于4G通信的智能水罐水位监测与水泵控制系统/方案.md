# 需求
## 功能需求
1. 自动控制
	- 使用24V 无刷直流隔膜泵向密闭储水罐补水
	- 水位 ≤ 低水位阈值 + 压力及其他安全条件正常 → 启动水泵补水
	- 水位 ≥ 高水位阈值→ 停止水泵
	- **压力约束+液位主控**
	- 压力采用上下阈值控制，不做PID恒压
	- 水泵支持PWM调速
2. 手动控制
	- 本地 START 启动。
	- 本地 STOP 停止。
	- 手动模式仍然必须经过安全保护判断，不能绕过保护。
3. 远程控制
	- 通过 ML307C + MQTT 实现。
	- 支持远程启动、停止、模式切换、参数配置和状态查看。
	- 远程 START 只是“启动请求”，最终是否运行由本地安全逻辑决定。
	- 断网不影响本地控制和保护。
## 检测需求
1. 液位检测
	- 使用超声波
	- 对应元器件：
2. 压力检测
	- 检测密闭罐顶部空气压力
	- 作为自动补水的安全约束量，并用于压力异常/过压保护
	- 用于过压保护
3. 水泵电压检测
	 - 检测 24V 水泵实际供电电压。
	- 用于欠压、过压、电源异常诊断。
4. 水泵电流检测
	- 检测启动电流、正常运行电流及异常电流。
	- 用于过流、堵转、空转等诊断。
## 控制需求
1. 上电默认停泵
	- 上电、复位、程序重新启动后，水泵默认关闭。
	- 不允许因为 MCU 初始化过程误启动。
2. 自动控制
	- 水位低于低水位阈值 + 压力及其他安全条件正常 → 允许启动补水
	- PWM 占空比可调，用于调节水泵转速。
3. 手动模式
	- 用户可通过 START / STOP 控制。
	- 手动控制不能绕过堵转、过流、过压等安全保护。
1. 最高优先级
## 安全保护需求
1. 堵转保护
	- 检测堵转异常。
	- 立即停泵。
	- 等待后有限次数自动重试。
	- 多次失败进入最终故障锁定。
2. 空转保护
	- 第一版先通过电流来检测
	- 发生空转后停泵并自动重试。
	- 多次失败后锁定
3. 过流保护
	- 运行电流持续超过允许范围时停泵并报警。
	- 必须区分正常启动电流和真正过流。
4. 欠压/过压保护
	- 24V 水泵供电异常时禁止启动或停止运行。 
5. 压力过高保护
	- 压力超过安全范围时立即停泵。
	- 密闭罐后续还应配置独立机械泄压措施，不能只依赖软件。
6. 传感器故障保护
	- 液位异常。
	- 压力异常。
	- 电压/电流采样异常。
	- 数据越界或长时间无有效数据。
7. 最长运行时间保护
	- 水泵连续运行超过设定时间后强制停止，防止传感器故障导致长期运行。

# 系统工作对象定义
1. 增加单向阀，密闭罐内部可能存在一定空气压力
```
罐内压力
↓
可能把水反向推回
↓
经过水泵
↓
回到外部水源
```
2. 供水位置：侧面下部进水
3. 顶部位置：超声波液位检测 罐内空气气压检测  安全泄压
4. 因为人工模拟  一个阀门 这样能实现这个水位变化

| 对象     | 当前定义                  | 作用                |
| ------ | --------------------- | ----------------- |
| 外部水源   | 普通开放水源/水箱             | 给补水泵提供水           |
| 补水泵    | 24V无刷直流隔膜泵，内置驱动，PWM控制 | 向密闭罐补水            |
| 单向阀    | 安装在水泵出口至储水罐之间         | 防止罐内压力把水反推回水源     |
| 进水口    | **密闭罐侧面偏下位置**         | 减少进水对顶部超声波水面测量的影响 |
| 储水罐    | 密闭、可承受实验压力            | 储水并形成顶部气相空间       |
| 超声波传感器 | 罐体顶部朝向水面              | 连续测量水位            |
| 压力传感器  | 顶部气相空间取压              | 检测罐内空气压力          |
| 安全泄压   | 顶部独立机械泄压装置            | 防止异常超压            |
| 出水口    | **侧面下部或罐底附近**         | 模拟正常用水            |
| 出水控制   | 第一版采用**手动阀门**         | 人工改变出水量，模拟持续/间歇用水 |

# 接口(引脚分布)，资源调试规划
## 引脚类型
1. 电源引脚：负责给芯片供电，不能当GPIO使用
2. 普通GPIO引脚
3. 模拟ADC引脚
4. 复用功能引脚
5. 时钟引脚
6. 启动和复位引脚
7. 调试引脚
## 引脚分配
### 分配规则
1. 引脚种类：固定引脚，有限选择引脚，自由GPIO
2. 分配顺序：固定系统引脚，模拟ADC,定时器与PWM，安全故障输入，UART等通信，IIC和SPI，普通GPIO,按键，LED,蜂鸣器，预留
### 固定引脚

| 功能    | 引脚           | 功能              |
| ----- | ------------ | --------------- |
| VBAT  | 第1脚          | 备份电源，禁止当 IO     |
| NRST  | 第7脚          | 复位专用，禁止普通占用     |
| VSSA  | 第8脚          | 模拟电源地，禁止数字信号占用  |
| VDDA  | 第9脚          | 模拟电源地，禁止数字信号占用  |
| VSS   | 23、35、47     | 数字电源地，禁止当 IO    |
| VDD   | 24、36、48     | 数字电源地，禁止当 IO    |
| SWDIO | PA13         | 调试口，禁止普通 IO 数据线 |
| SWCLK | PA14         | 调试口，禁止普通 IO 时钟线 |
| BOOT0 | 第44脚         | 启动选择，禁止普通占用     |
| BOOT1 | PB2          | 启动选择，禁止普通 IO    |
| 高速晶振  | PD0、PD1      | HSE 晶振专用        |
| 低速晶振  | PC14、PC15，可选 | LSE 可选          |
### 优先分配ADC
STM32F103CBT6 LQFP48主要ADC引脚：`PA0～PA7 PB0～PB1`

| 功能     | STM32引脚 | 外设功能     | 说明            |
| ------ | ------- | -------- | ------------- |
| 罐体压力检测 | PA0     | ADC1_IN0 | 压力传感器模拟电压     |
| 水泵电压检测 | PA1     | ADC1_IN1 | 24V经过分压、滤波后输入 |
| 水泵电流检测 | PA4     | ADC1_IN4 | 电流传感器输出       |
| 备用模拟量1 | PA5     | ADC1_IN5 | 预留            |
| 备用模拟量2 | PA7     | ADC1_IN7 | 预留            |
