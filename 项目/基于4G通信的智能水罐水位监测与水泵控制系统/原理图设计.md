## 晶振电路
### 元器件的选择
#### 晶振选择
1. 使用外部晶振，stm32内部虽然有HSI内部RC时钟，但是晶振和外部稳定性不如外部晶体
2. 所有选用外部8MHz晶振
	- 更准确的系统时钟；
	- 稳定的UART波特率；
	- 稳定的定时器时间；
	- 方便系统运行到72MHz；
	- 为后续通信、采样提供稳定的时间基准。‘
3. 时钟关系
```
8MHz外部晶振
     ↓
STM32内部PLL
     ↓ ×9
72MHz系统时钟
```
4. 选择8MHz的原因：STM32F103系列常使用72MHz
#### 电容选择
1. 电容的选择取决于晶振的负载电容
2. 负载电容 `CL=20pF`
##### 计算对应的电容容值
1. 计算公式：

$CL=C1C2C1+C2+CSC_L=\frac{C_1C_2}{C_1+C_2}+C_S$

其中：

- $C_L$：晶体数据手册要求的负载电容；
- $C_1$：OSC_IN一侧的电容；
- $C_2$：OSC_OUT一侧的电容；
- $C_S$：寄生电容；
- 寄生电容来自STM32引脚、PCB走线、晶体焊盘等
2. 若两个电容相同，公式可简化为
$CL=C2+CSC_L=\frac{C}{2}+C_S$
$C=2(CL​−CS​)$
3. 通过上面公式，主要是寄生电容大小`3～5pF`
4. 最终推论就是33pF

## OLED
### 上拉电阻
```
     +3V3
       │
    R6 4.7kΩ
       │
OLED_SCL────────J2-2
```
1. 设计原因：IIC 总线SCL SDA 使用“开漏输出”
2. 开漏输出可以理解为两个动作
	- 把通信线拉到低，产生低电平
	- 松开通信线，不主动产生高电平
	- 为了产生高电平，当松开STM32松开线路时，4.7kΩ电阻把线路拉到3.3V,从而产生高电平
3. 为啥选择`4.7kΩ`
	- 上拉电阻不能太小，否职责拉低时候电流太大
	- 上拉电阻不能太大，否则信号上升太慢
	- 所以有一个允许范围：`Rmin​≤RP​≤Rmax`
	- I²C上拉电阻的下限由拉低电流决定，上限由上升时间和总线电容决定
####  最小电阻：由拉低电流决定​
1. STM32或OLED把总线拉低时，电流会从3.3V经过上拉电阻流向GND
	- 电源电压：3.3V 
	- 低电平最大电压：约0.4V
	- 允许拉低电流：约3mA
2. 最小电阻为：


$$Rmin=3.3V−0.4V3mAR_{min}=\frac{3.3V-0.4V}{3mA} Rmin≈967ΩR_{min}\approx967\Omega
$$

- **3.3V−0.4V=2.9V**：这是**电阻两端的实际电压**。因为当器件拉低总线时，引脚并不是绝对的0V，它有一个“低电平最大电压”，图中设定为 0.4V0.4V。所以加在电阻两端的电压是 3.3V−0.4V3.3V−0.4V
- **3mA（即 0.003A）**：这是**允许的最大拉低电流**。STM32或OLED的引脚灌电流能力有限（图中设定为3mA），如果电流太大，可能会烧毁引脚或导致低电平不够低
 3. 如果采用4.7kΩ,拉低电流大约是：
 如果使用4.7kΩ，拉低时电流大约是：

$$I=3.3V4.7kΩ≈0.7mAI=\frac{3.3V}{4.7k\Omega}\approx0.7mA$$

0.7mA比较小，STM32和OLED都很容易把线路拉低。
 
#### 最大电阻：由信号上升速度决定
1. I²C线路有寄生电容
2. 寄生电容：PCB走线、连接器、OLED模块和芯片引脚共同形成的小电容。电阻必须给这个电容充电，电阻越大，充电越慢，信号上升越慢。
3. 所以IIC的上升时间就决定了这个信号的上升速度
$tr=0.8473×RP×CBt_r=0.8473\times R_P\times C_B$
4. 最大电阻
$Rmax=tr(max)0.8473×CBR_{max}=\frac{t_{r(max)}}{0.8473\times C_B}$
5. 参数
	- I²C速度：100kHz；
	- 允许上升时间：1000ns；
	- 总线电容估算：100pF。
6. 故计算得出
$Rmax=1000ns0.8473×100pFR_{max}= \frac{1000ns}{0.8473\times100pF} Rmax​≈11.8kΩ$
#### 允许范围

 $1kΩ≤RP​≤11.8kΩ$
 1. 4.7kΩ处在中间位置
	 - 拉低电流不大
	 - 上升速度足够快
	 - 对短距离100kHz I²C非常通用
	 - 常见默认值
### 滤波电容
1. OLED并不是一直消耗完全相同的电流,发生以下动作时候，电流会突然变化
	- 刚刚点亮屏幕
	- 刷新整屏
	- 显示大量白色像素
	- OLED 内部升压电压工作
2. 容量选择：100nF + 4.7µF或10µF
3. 两种不同的容量，并不是重复元件，而是负责不同速度的干扰

|电容|主要作用|
|---|---|
|100nF|处理非常快速的高频尖峰|
|4.7µF～10µF|处理屏幕刷新、亮度变化等较慢电流波动|
4. 100nF 反应快，但是储存的电量少
	- 电量少，容量少，储存的电荷量少
	- 反应快：寄生电容ESL（电感）极小 内部极板小、引脚短、结构紧凑。这意味着它的**寄生电感（ESL）极小**  所以对于高频干扰（电流变化极快的由很好的作用）
5. `10µF`储存的电量多，但对极高频干扰不如100nF有效
	- 电量多
	- 高频差；如果是电解电容，体积大的陶瓷电容，他的引脚长，内部卷绕结构多，寄生电感(ESL)非常大,故在高频的情况下，使用100nf
6. 两个并联使用，兼顾高频滤波和瞬时储能
7. PCB防止位置：高频小电容最靠近芯片电源脚，大容量电容放在附近作为储能
	- 100nF处理的是非常快速的电流变化，比如芯片内部数字电路切换产生的高频尖峰。  所以放置在芯片引脚旁
	- 10µF它储存的电荷更多，主要处理持续时间更长的电流变化
		- OLED整屏刷新
		- OLED刚刚启动
		- 显示内容突然变亮
		- 连接线产生的短时间压降
	- 这些变化没有数字尖峰那么快，因此允许电流通过稍长一点的路径
8. 三个供电阶段
	高速瞬间→100nF立即供电→10uF继续支撑→3.3V持续供电
## 指示灯
### 接法
1. 高电平点亮
	- GPIO输出高电平，LED亮
	- GPIO输出低电平：LED灭
2. 电阻位置（两种方案）
	- GPIO → 电阻 → LED → GND
	- GPIO → LED → 电阻 → GND
	- 两种方案在电气上是完全相同的（属于串联电路，同一条支路中的电流完全相同）
3. LED 符号：三角 = 阳极（正极），竖线 = 阴极（负极，接 GND）  **树荫**
### 电阻值的选择
1. STM32 GPIO：约 3.3V
2. LED 正向压降 VFV_F：约 2.0V
	- LED 正向压降 VF：电流流过一个器件之后，这个器件两端产生的电压差
3. 目标 IF ≈ 3~5mA（建议通过led的电流）
4. 所以通过计算可以得到大约是4mA

$R=VGPIO−VFILEDR=\frac{V_{GPIO}-V_F}{I_{LED}}$
## 蜂鸣器电路
### 蜂鸣器选型
#### 有源蜂鸣器
1. 内部由振荡电流，通电产生固定频率
2. 驱动：直流电平控制，GPIO 输出高→MOS 导通→上电鸣叫；低电平→断电停止，**不需要 PWM**
3. 引脚：有正负极
4. 音调：只能是滴答声音，不能播放音乐
5. 电流：典型20~30mA
#### 无源蜂鸣器
1. 只有线圈+振膜，没有振荡电路
2. 驱动：必须给我PWM方波，改变 PWM 频率就能改变音调，可以播放简单乐曲
3. 引脚：不分正负极
4. 电流：一般很小，几 mA
5. 缺点：代码复杂需要配置定时器PWM,可以做不同音调，音乐

#### 电路如何工作
##### BUZZER_EN = 低电平
1. Q2栅极约为0V→Q2关闭→蜂鸣器负极不能接通GND→没有完整的回路→蜂鸣器不响
2. 电路处于断开状态：
	`+5V_SYS → 蜂鸣器 → Q2关闭 → 无法到达GND `
##### BUZZER_EN = 高电平
1. STM32输出3.3V→3.3V经过R14送到Q2栅极→Q2导通→蜂鸣器负极通过Q2接到GND→蜂鸣器获得约5V供电→蜂鸣器鸣叫
2. 完整回路：
` +5V_SYS→蜂鸣器→Q2漏极D→Q2源极S→GND `
#### 为啥不用STM32直接驱动蜂鸣器
1. STM32的GPIO输出电压是3.3V，允许输出的电流也比较有限，而5V蜂鸣器可能需要：20mA、30mA、50mA，甚至更大
2. 如果直接连接GPIO，可能出现
	- 蜂鸣器声音很小
	- GPIO电压被拉低
	- STM32工作异常
	- GPIO长期过流损坏
3. STM32只控制MOSFET MOSFET负责通过蜂鸣器电流
4. GPIO驱动MOSFET栅极时，稳定状态下几乎不消耗持续电流
#### Q2 AO3400A的作用
1. AO3400A是N沟道MOSFET，这里作为低端开关
2. 低端开关：开关介于负载与GND之间
3. 使用低端开关的原因是：
	- 电路简单
	- STM32的3.3V可以直接控制
	- 不需要额外高端驱动芯片；
	- 关闭和开启逻辑容易理解；
	- 适合蜂鸣器、继电器、小灯等负载。
#### R14为什么是100Ω
MOSFET 的Gate是一个小电容 蜂鸣器开关的时候要进行这个小电容的充放电，同时电容两端的电压是不能变的，所以加一个电阻是最好的，防止电流的瞬变
1. MOSFET的栅极不是普通电阻负载，可以把它近似理解成一个小电容
2. STM32改变输出电平时，需要给这个“栅极电容”快速充电或放电
3. 切换瞬间可能产生较大的短时电流，同时快速边沿也更容易产生干扰
4. 加入电阻以后
	- **限制栅极瞬间充放电电流**；
	- 减小高频振铃；
	- 降低开关干扰；
	- 对STM32的GPIO提供一定保护
5. 蜂鸣器开关很慢，47Ω～220Ω都可以 100Ω是常用值
#### R15为什么是10kΩ
1. R15是栅极下拉电阻，它负责保证Q2默认关闭
2. stm32刚上电或复位,gpio属于高阻抗状态，如果没有R15，MOSFET栅极可能悬空并积累电荷
	- Q2误导通；
	- 蜂鸣器上电乱叫；
	- 蜂鸣器偶尔发出短促声音。
3. 电阻吧栅极稳定拉到GND
```
MCU未初始化 → R15把栅极拉低 → Q2关闭 → 蜂鸣器保持关闭
```
4. 为啥选择10kΩ，估算STM32输出高电平时通过R15的电流：

$I=3.3V10kΩ=0.33mAI=\frac{3.3V}{10k\Omega}=0.33mA$

这个电流很小，不会明显增加GPIO负担，同时下拉能力足够。
#### D3 SS14为什么反向连接
1. 续流二极管
	- 阳极：+5V_SYS
	- 阴极：Q2漏极/蜂鸣器负极
2. 正常工作时，D3处于反向截至状态，不参与蜂鸣器正常电流
3. 如果蜂鸣器是电磁式蜂鸣器，内部会有线圈，线圈电流不能立即消失，会产生一个较高的反向电压尖峰
4. 如果没有SS14
```
Q2关闭 → 蜂鸣器线圈产生高压尖峰 → 尖峰加到Q2漏极 → 可能干扰STM32或损坏Q2
```
5. 有D3时，线圈电流通过D3形成释放回路，尖峰被限制
6. 线路不能接反，如果接反，Q2导通就会形成近似短路（+5V_SYS → D3 → Q2 → GND）
