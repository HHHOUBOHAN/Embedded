## printf 重定向
```c
/* USER CODE BEGIN 0 */
int fputc(int ch, FILE *f)
{
    HAL_UART_Transmit(&huart3, (uint8_t *)&ch, 1, 50);
    return ch;
}
/* USER CODE END 0 */
```
1. 重写`fputc()`  ：你别往电脑屏幕输出了，你往串口 USART3 输出
2. 关于这个`\r\n` 和单独使用`\n`的区别
	- 只写`\n`![[Pasted image 20260703142825.png]]
	- \n 只负责往下一行走  但是没有回到最左边 
	- 写了`\r\n`![[Pasted image 20260703142911.png]]
3. `buffer` 只是一个临时字符串数组，每次 `sprintf()` 都会把新的内容写进去，覆盖掉旧内容
