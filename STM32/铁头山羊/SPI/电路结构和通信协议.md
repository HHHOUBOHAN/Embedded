2. 引脚含义
	- MOSI - Master Output Salve Input - 主发从收
	- MISO - Master Input Salve Output - 主收从发
	- SCK - Serial Clock - 串行时钟（用于传输时钟信号，主机产生信号，从机接收信号）
	- NSS - Negative Slave Select - 从机选择(低电压有效)（主机于从机进行通讯，通信输入低电压，不通信输入高电压）

# 3. 参数1: 时钟信号的极性和相位
## 3.1 极性
1. 空闲状态时，`SCK`电压是低电压，极性为低极性
2. 空闲状态时，`SCK`电压是高电压，极性为高极性
## 3.2 相位
![[Pasted image 20260824101510.png]]
1. **第1边沿**：指 SCK 从**空闲状态**跳变出来的**第一个动作**（要么由低变高，要么由高变低）。
2. **第2边沿**：指紧接着第1边沿之后的**第二个动作**（方向与第1边沿相反）

|极性（CPOL）|空闲电平|第1边沿（第一个跳变）|第2边沿（第二个跳变）|
|---|---|---|---|
|**极性 = 低（CPOL=0）**|空闲时 SCK 为 **0（低电平）**|**上升沿**（0→1）|**下降沿**（1→0）|
|**极性 = 高（CPOL=1）**|空闲时 SCK 为 **1（高电平）**|**下降沿**（1→0）|**上升沿**（0→1）|
