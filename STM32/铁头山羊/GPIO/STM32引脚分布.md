# 特殊引脚的功能和作用
## 特殊引脚
1.  VDD - 供电+（接3.3V）
2. VSS - 地（接地0V）
3. NRST - 复位（接复位按钮）
4. VBAT - 备用电池
5. BOOT0 - 启动模式选择
# 普通引脚的命名规则
1. 以字母为组编号（每组最多有16个引脚)
2. 以数字为引脚编号
