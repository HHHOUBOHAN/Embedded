# ADC简介
##  12位 逐次逼近型 ADC *2
  
1. ADC模拟-数字转换器（自然界->单片机）
2. 模拟信号和数字信号对比

| 信号类型 | 特点                | 举例              | 取值范围    | 单片机处理方式   |
| ---- | ----------------- | --------------- | ------- | --------- |
| 模拟信号 | 连续变化，中间有无数个值      | 自然界：声音、温度、电压、电流 | 可以取无数个值 | 需要 ADC 转换 |
| 数字信号 | 离散变化，通常用 0 和 1 表示 | 开关信号、高低电平、二进制数据 | 只能取有限个值 | 可以直接读取    |
3. `12位`表示的采样深度（用多少为二进制数来表示一个采样点）
	- 输入电压（0~3.3V）                                            数字（二进制）
	- 模拟信号（0~3.3V）             四位ADC                 数字信号（0000b~1111b）
	- 把0~3.3V                              分成`2^4-1`份           每份=0.22V
	- 衡量ADC性能的重要指标：ADC采样深度（ADC采样深度越深，转换的结果越精细）
4. `逐次逼近型`
	- 逐次逼近型(ADC最常见的一种类型)
	- 举例：类似于天平称重（通过不断的调整砝码的总和，最终接近最终质量）
	- 逐次逼近型ADC内部结构（采样深度=4bit）![[Pasted image 20260702221330.png]]
	- 应用：
		1. 模拟信号的输入（类似于天平的实物即模拟信号）
			- 输入模拟信号2.21V
			- 开关闭合 输入电压对电容充电
			- 当电容冲满电后 $C_{ADC}$的电压就等于输入的模拟信号的电压2.21V
			- 把开关断开（通过模电可知从电容两个方向电流`i=0`）故电容电压一直维持2.21V
			- 通过两个圆圈可知这个两端都维持+（2.21V）![[Pasted image 20260702222530.png]]
			- 采样保持电路作用：将输入电压采集下来，通过电容储能形式，保证输入的电压在后序转换过程中保持不变
		2. 数字信号的计算（类似于通过砝码称重）
			- 通过从`b3~b0`从大到小的比较来确定对应位置的数字（总和小于目标值即为1，总和大于就为0）![[Pasted image 20260702223307.png]]

## ADC采样时间和转换时间
### 采样时间和转换时间
1. ADC 一次读取电压需要的两个时间=采样时间+转换时间
2. 采样时间：先把模拟电压“抓住”
	- 采样时间：就是 ADC 内部的小电容 $C_{\mathrm{ADC}}$ 去接收外部模拟电压的时间
		外部模拟电压
		↓
		给 ADC 内部电容充电
		↓
		电容电压接近输入电压
	- 让 ADC 内部电容充到正确电压所需要的时间
3. 转换时间：再把这个电压变成数字
	- 转换时间：就是 ADC 把刚才采样到的电压转换成数字的时间
	- STM32 12 位 ADC，转换结果范围是：`0 ~ 4095`
	- 如果参考电压是3.3V
		0V    -> 0
		1.65V -> 2048
		3.3V  -> 4095
	- 转换时间：ADC 采样完成后，就要通过内部比较器、逐次逼近电路，把电压变成数字值的过程就是转换时间、
