# GPIO
## `GPIO_Init`
1. `GPIO_Init` :初始化IO引脚(配置IO引脚参数)
```c
void GPIO_Init(GPIOTypeDef *GPIOx,                  //端口号，取A B C D..
               GPIO_InitTypeDef *GPIO_InistStruct); //初始化的参数
```
2. 初始化一枚IO引脚
```c
typedef struct
{
    uint32_t GPIO_Pin;              // 选择引脚：GPIO_Pin_0 ~ GPIO_Pin_15

    GPIOMode_TypeDef GPIO_Mode;     // 工作模式：输入、输出、复用、模拟

    GPIOSpeed_TypeDef GPIO_Speed;   // 输出速度：2MHz、25MHz、50MHz、100MHz

    GPIOOType_TypeDef GPIO_OType;   // 输出类型：推挽、开漏

    GPIOPuPd_TypeDef GPIO_PuPd;     // 上拉下拉：无上拉下拉、上拉、下拉

} GPIO_InitTypeDef;
```

4. `GPIO_WriteBit`：向输出数据寄存器写1个比特位
5. `GPIO_ReadOutDataBit`:从输出数据寄存器读1个比特位
6. `GPIO_ReadInputDataBit`：从输入数据寄存器度1个比特位
7. `GPIO_SetBits`:把某个 GPIO 引脚输出高电平
