# 如何熄灭LED
1. 电路图                             ![[Pasted image 20260704112818.png]]
	- 第一个和第二个图通过拨动开关控制LED的熄灭
2. IO引脚（**推挽模式**）来替代开关![[Pasted image 20260704111902.png]]
	- 这个IO引脚是推挽模式：`MOS`管是交替导通的，输入1是高电平点亮，输入0是低电平熄灭
3.  IO引脚（**开漏模式**）来替代开关![[Pasted image 20260704112507.png]]
	- 这个0 对应是`N-MOS`连通 从而实现低电平  这个1代表，`N-MOS`和`P-MOS`都断开，实现高阻抗
4. STM32F40xxx指示灯电路图                                                       ![[Pasted image 20260704113257.png]]
	- `LED1 + R50` 是电源指示灯，不受 MCU 控制，上电就亮
	- 板载 `PA5 LED`：推荐推挽输出  点亮方式：低电平亮，高电平灭
	- 判断开漏和推挽的方法: 
		1. 看 LED 接哪里：
		- LED 接 VCC，GPIO 拉低亮 → 低电平点亮
		- LED 接 GND，GPIO 拉高亮 → 高电平点亮
		1. 看是LED是否特殊
		- 普通 LED：默认推挽
		- 需要共线/只拉低/靠上拉：才考虑开漏
