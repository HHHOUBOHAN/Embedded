# 上升时间，下降时间和保持时间的概念
1. 理想情况：向IO引脚写0或1会瞬间从高电压变成低电压（低电压变成高电压）**一瞬间完成变化**
2. 实际情况：会存在上升时间，下降时间，输出有效电压的是保持时间
3. 上升时间：电平从低电平变成高电平所花的时间
4. 下降时间：电平从高电平变成低电平所花的时间
5. 保持时间：电平稳定在某个状态的时间

# 最大输出速度应如何选择
1. **GPIO 输出速度的分类**：低速（最大输出频率2MHz）,中速（最大输出频率10MHz）,高速（最大输出频率50MHz）
2. **选择原则**：选取满足要求的最小值（过于陡峭的边会增加耗电，并引入EMI问题（对其他电子元器件产生电磁干扰））
3. 应用

| 速度       | 上升/下降时间 | 干扰  | 适合       |
| -------- | ------- | --- | -------- |
| 低速 2MHz  | 慢       | 小   | LED、蜂鸣器  |
| 中速 10MHz | 中等      | 中等  | 普通通信     |
| 高速 50MHz | 快       | 大   | SPI、高速信号 |
