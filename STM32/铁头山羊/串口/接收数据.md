# 回顾接收数据的过程
1. 内部结构框图![[Pasted image 20260705194041.png]]
 2. 流程
 ```
   外部设备 TX 引脚发送串行波形  
	↓  
	本机 USART 的 RX 引脚接收波形  
	↓  
	接收移位寄存器一位一位接收  
	↓  
	凑够一帧数据后转成一个字节  
	↓  
	放入接收数据寄存器  
	↓  
	RXNE 标志位置 1  
	↓  
	CPU 读取接收数据寄存器
 ```
 3. 核心：串行数据 → 并行数据
# RxNE标志位
1. RxNE: Receive Data Register Not Empty - 接收数据寄存器非空    
2. 当RDR非空时，RxNE=1；否则RxNE=0
3. 作用：判断 USART 是否接收到了新的数据
4. `RxNE = 1` 表示：  
	- 接收数据寄存器里面已经有数据  
	- CPU 可以读取这个数据  
	- 可以调用 `USART_ReceiveData()` 取出数据  
5. `RxNE = 0` 表示：  
	- 接收数据寄存器为空  
	- 当前没有新的数据可以读取
# 接收代码的编写方法
```c
uint16_t USART_ReceiveData(USARTTypeDef *USARTx); //串口名称
```
1. 作用：从接收数据寄存器读取数据
2. 返回 `uint16_t`，主要是为了兼容 USART 的 **8 位数据位 / 9 位数据位**
3. RXNE = 1 表示有数据   RXNE = 0 表示没有数据
# 使用串口控制LED
```c
#include "stm32f4xx.h"
#include "stm32f4xx_gpio.h"
#include "stm32f4xx_rcc.h"
#include "stm32f4xx_usart.h"
 
 
void My_USART_Init(void);
void My_OnBoardLED_Init(void);
 
int main(void)
{ 
	My_USART_Init();
	My_OnBoardLED_Init();
	while(1)
	{
		//#1. 等待接收数据寄存器ROR非空
		while(USART_GetFlagStatus(USART3,USART_FLAG_RXNE)==RESET);
		//#2.读取数据
		uint16_t ReceiveData=USART_ReceiveData(USART3);
		//#3.数据处理
		if(ReceiveData=='1')
		{
			GPIO_ResetBits(GPIOA,GPIO_Pin_5);
		}
		else if(ReceiveData=='0')
		{
			GPIO_SetBits(GPIOA,GPIO_Pin_5);
		}
	}
}
 
//@简介：对 USART3 进行初始化
//PC10 --- USART3_TX
//PC11 --- USART3_RX
//通信参数：115200, 8位数据位, 1位停止位, 无校验, 收发双向
void My_USART_Init(void)
{
	//#1.两个结构体配置参数GPIO USART
	GPIO_InitTypeDef GPIO_InitStruct;
	USART_InitTypeDef USART_InitStruct;
	
	
	//#2.开启时钟
	//STM32F407 里 GPIOA/GPIOB/GPIOC 这些 GPIO 都挂在：AHB1 总线
	RCC_AHB1PeriphClockCmd(RCC_AHB1Periph_GPIOC,ENABLE);
	//USART3 挂在 APB1 总线
	RCC_APB1PeriphClockCmd(RCC_APB1Periph_USART3,ENABLE);
	
	
	
  //3.配置 PB6/PB7
	GPIO_InitStruct.GPIO_Pin= GPIO_Pin_10|GPIO_Pin_11;
	GPIO_InitStruct.GPIO_Mode=GPIO_Mode_AF;//复用功能模式  串口引脚必须用复用模式
	GPIO_InitStruct.GPIO_OType = GPIO_OType_PP;//推挽
	GPIO_InitStruct.GPIO_PuPd=GPIO_PuPd_UP;//上拉
	GPIO_InitStruct.GPIO_Speed = GPIO_Speed_50MHz;
	GPIO_Init(GPIOC,&GPIO_InitStruct);
	
	//4.配置USART1 参数
	USART_InitStruct.USART_Mode = USART_Mode_Tx | USART_Mode_Rx;
	USART_InitStruct.USART_BaudRate=115200;//波特率
	USART_InitStruct.USART_WordLength=USART_WordLength_8b;//数据位8位
	USART_InitStruct.USART_StopBits=USART_StopBits_1;//停止位1位
	USART_InitStruct.USART_Parity=USART_Parity_No;//无校验位
	USART_InitStruct.USART_HardwareFlowControl = USART_HardwareFlowControl_None;//不用硬件流控制
	USART_Init(USART3,&USART_InitStruct);
	
	
	//5.指定PB6/PB7为串口引脚复用
	GPIO_PinAFConfig(GPIOC, GPIO_PinSource10, GPIO_AF_USART3);
  GPIO_PinAFConfig(GPIOC, GPIO_PinSource11, GPIO_AF_USART3); 
	USART_Cmd(USART3, ENABLE);
}
void My_OnBoardLED_Init(void)
{
	GPIO_InitTypeDef GPIO_InitStruct;
	RCC_AHB1PeriphClockCmd(RCC_AHB1Periph_GPIOA,ENABLE);
	GPIO_InitStruct.GPIO_Pin=GPIO_Pin_5;
	GPIO_InitStruct.GPIO_Mode=GPIO_Mode_OUT;
	GPIO_InitStruct.GPIO_OType=GPIO_OType_PP;//推挽
	GPIO_InitStruct.GPIO_PuPd=GPIO_PuPd_NOPULL;
	GPIO_InitStruct.GPIO_Speed=GPIO_Speed_2MHz;
	GPIO_Init(GPIOA,&GPIO_InitStruct);	
	
	GPIO_SetBits(GPIOA,GPIO_Pin_5);//PA5 LED 是 低电平亮 故先输出高电平 让其没有电位差
	//让 PA5 输出高电平，接近 3.3V
}
```

# 错误标志
## PE
1. PE: Parity Error - 奇偶校验错   如果接收到的数据有校验错误，则 PE=1；否则 PE=0
2. ![[Pasted image 20260705203058.png]]
## FE
1. FE: Frame Error - 帧格式错误  接收到了无效的数据帧，则 FE=1；否则 FE=0
2. ![[Pasted image 20260705203313.png]]
## NE
1. NE: Noise Error - 噪声错    接收的数据中检测到了噪声，则 NE=1；否则 NE=0
2. ![[Pasted image 20260705203409.png]]
## ORE
1. ORE: Overrun Error - 过载错   由于过载造成了数据丢失，则 ORE=1；否则 ORE=0
2. ![[Pasted image 20260705203522.png]]
3. 发数据的速度比收数据的速度要快 字节2就会被这个字节3给覆盖
