# TxE标志位
1. TxE: Transmit Data Register Empty - 发送数据寄存器空  当TDR空时，TxE=1；否则TxE=0![[Pasted image 20260705152845.png]]
2. 作用：告诉 CPU：发送数据寄存器现在空了，可以继续写下一个数据了
# TC标志位
1. TC: Transmit Complete - 发送完成  当TDR空且移位寄存器空时，TC=1；否则TC=0![[Pasted image 20260705153642.png]]
2. 作用：告诉 CPU：这一帧数据已经真正从 TX 引脚发送完了（发送数据寄存器 TDR 已经空了
并且发送移位寄存器也已经空了）结果就是：数据已经彻底从 TX 引脚发出去了
# 编程接口
## USART_Cmd
```c
void USART_Cmd(USARTTypeDef *USARTx, //串口名称

               FunctionalState NewState); //ENABLE-使能；DISABLE-禁止
```
1. 作用：控制USART模块的使能和禁止（总开关）
2. 示例代码：
```c
// 使能USART1
USART_Cmd(USART1, ENABLE);


// 禁止USART1
USART_Cmd(USART1, DISABLE);
```
## USART_GetFlagStatus
```c
FlagStatus USART_GetFlagStatus(USARTTypeDef *USARTx, //串口名称

                               uint16_t USART_FLAG); //要查询的标志位
```
1. 作用：查询USART标志位的值。返回值：RESET - 0； SET - 1
2. 标志位：
```c
标志位：

USART_FLAG_TXE // TXE    USART_FALG_RXNE // RXNE

USART_FLAG_TC  // TC     USART_FALG_PE   // PE
```
3. 应用：
```c
if(USART_GetFlagStatus(USART1, USART_FLAG_TXE) == SET){ // 判断发送数据寄存器是否为空

    ...

}

if(USART_GetFlagStatus(USART1, USART_FLAG_TC) == SET){ // 判断数据发送是否完成

    ...

}
```
## USART_SendData
```c
void USART_SendData(USARTTypeDef *USARTx, //串口名称

                    uint16_t Data); //要发送的数据
```
1. 作用：把要发送的数据写入到发送数据寄存器里
2. 示例：
```c
// 发送字节0x01

USART_SendData(USART1, 0x01);
```
