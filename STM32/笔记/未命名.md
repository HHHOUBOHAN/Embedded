# PWM原理：

## 1. PWM简介：

PWM是一种数字信号，是英文“Pulse Width Modulation”的缩写，叫做 脉冲宽度调制，也就是控制脉冲宽度的大小，在嵌入式输出控制中除了有高低电平控制LED灯的亮灭，也可以通过PWM控制灯的亮度大小。

PWM适用场景：

1.LED灯调光，如手机亮度调节，显示器背光控制，台灯亮度调节等

2.电机调速，如电风扇，笔记本散热风扇，空调吹风机转速调节等

3.音频功放，音箱，耳机的D 类音频功放

## 2.PWM的基本工作原理：

通过改变高电平和低电平的时间比例，可以实现对输出电平的控制。调整高电平时间比例可以改变输出电平的平均值，从而实现对设备的控制。

## 3.PWM的主要参数：

（1）占空比：指的是在一个周期内高电平所占时间的百分比

（2）频率：频率是指1秒钟时间信号进行一次高低电平跳变（周期）的次数，也就是1秒钟有多少个周期，频率大小决定了一个周期时间的长短，两者呈反比关系，频率上限由定时器挂载的总线频率决定

（3）分辨率：是占空比的可调精细程度（即占空比能被划分成多少个“可调等级”）

## 4.PWM实现流程（根据星辰派所使用的STM32F407ZET6芯片说明）：

定时器类型共有三种分别为高级定时器（TIM1、TIM8），通用定时器（TIM2~TIM5、TIM9~TIM14），普通定时器（TIM6、TIM7）三种

其中除了普通定时器无PWM输出功能，其他的定时器都可以产生PWM输出。每个通用定时器都有独立的通道可以用来作为：输入捕获、输出比较、PWM输出、单脉冲模式输出等。其中，高级定时器TIM1、TIM8可以同时产生7路PWM输出，除此之外，高级定时器还有互补输出，死区生成，刹车功能。

PWM的互补输出：简单说就是控制器同时输出两路 “相反” 的 PWM 信号：一路高电平时另一路低电平，专门用来驱动电机、电源里的上下两个开关器件，让它们交替工作，不用额外加反向电路，控制更简单。

PWM的死区控制：因为开关器件关断有延迟，若两路互补信号直接切换，可能出现上下开关 “同时导通”（短路），死区就是在切换时加一段极短的 “空窗期”，让两个开关都先关断，等上一个彻底关死，再开下一个，避免短路烧器件。

PWM的刹车功能：就是紧急停止功能：遇到过流、过温、按急停按钮等异常情况时，立刻切断所有 PWM 信号，让电机 / 电源停止工作

把定时器计数比作 “运动员跑步”：

- 计数器 CNT：运动员，从 0 开始向上跑（向上计数模式）；
- 自动重载值 ARR：终点线，运动员跑到 ARR 后立即回到 0 重新跑；
- 比较值 CCRx：赛道标记点，运动员跑到 CCRx 时，GPIO 电平翻转；

在PWM输出模式下，除了CNT（计数器当前值）、ARR（自动重装载值）之外，还多了一个值CCRx（捕获/比较寄存器值）。

当CNT小于CCRx时，TIMx_CHx通道输出低电平；

当CNT等于或大于CCRx时，TIMx_CHx通道输出高电平。

PWM的一个周期

定时器从0开始向上计数，CNT的值不断增加

当CNT的值小于CCRx的值时，引脚输出低电平

当CNT的值大于CCRx的值时，引脚输出高电平

当CNT的值达到ARR时，代表一个周期完成，CNT的值归0重新计数
